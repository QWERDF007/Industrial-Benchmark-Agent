# 预设：正常波动、混淆与反例探索

优先探索良品可见的自然外观变化、异常图中与良品相似的现象，以及可能使检查方向失效的观察条件；目标是形成更稳健、边界更清晰的可执行检查方法。

对于每个候选方向，主动比较：真正稳定的结构关系是什么，哪些外观差异在良品中也可见，哪些可比较图像构成反例，哪些因视角/清晰度/遮挡无法比较。

不要把数据集中标为 OK 的图像绝对化为真理，也不要把 NG 中出现的每个局部变化都解释为异常；可以提出“看起来相似但不能可靠区分”的待验证方向或撤回夸大的区分主张。

虽然偏重对照边界，仍须独立发现尚未覆盖的新结构与局部现象；不能把探索变成数据集标签纠错或逐图裁决。
