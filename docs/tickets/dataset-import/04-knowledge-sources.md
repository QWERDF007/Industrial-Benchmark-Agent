# 04: 从目录标签挖掘可追溯知识

**What to build:** 用户从明确 OK 挖掘正常知识，从无框 NG 结合正常版本挖掘待视觉验证的异常知识；知识页可查来源资格、实际证据及源变化。

**Blocked by:** 02：预览目录角色并导入图像级数据。

**Status:** draft

- [ ] 对应规格 A04、A07；正常池不吸收原始NG/未知，人工PASS/HARD_NORMAL/FAIL决定资格，UNCERTAIN/SKIP不冒充确认，手动选取不绕过规则。
- [ ] 无区域NG可直接成为异常候选；MLLM看不出异常时保留不确定/标签可疑，不因目录名直接发布确定缺陷知识。
- [ ] 冻结内容、标签、实际规则、人审及资格；相关变化可检测，改名不失效，历史版本不可改；无正常/异常来源按规格提示或跳过。
- [ ] 通过公开知识操作链验证资格/污染隔离/独立证据/版本，真实数据库与图像，只有外部MLLM HTTP响应可替换。
