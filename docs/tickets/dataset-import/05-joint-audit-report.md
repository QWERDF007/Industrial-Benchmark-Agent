**Blocked by:** 04：从目录标签挖掘可追溯知识。

**Status:** draft

- [ ] 对应规格 A08～A10；无区域使用原分辨率覆盖块，必要时追加模型ROI；多图联合、位置/光照关联、实际容量分批及真实证据引用贯通工作台。
