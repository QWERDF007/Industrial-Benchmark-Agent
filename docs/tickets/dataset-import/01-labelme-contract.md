# 01: 统一格式契约并贯通 Labelme 导入

**What to build:** 用户继续通过页面或 DSH 接入 Labelme，并在列表与详情看到明确格式。格式、预览/导入请求、样本统计共用一个契约，为目录格式提供同一条可扩展接入链。

**Blocked by:** None (can start immediately)。

**Status:** completed

- [x] 对应规格 A01、A02、A05；Labelme 仍支持独立或相同图像/标注目录及矩形、多边形、Mask，原始数量与来源保持真实。
- [x] 格式分支字段校验由领域执行，页面/HTTP/DSH 类型一致；需要的整理随本贯通流程交付，不创建平行旧新入口或泛化框架。
- [x] 既有持久化配置通过明确迁移保留身份和历史，当前调用方统一更新，非法格式/字段有可读错误。
- [x] 公开工作台和原生导入查询返回同一数据集/计数，真实临时库/文件验证，代码保持可构建；先取得失败测试再实现。
