# 08: Agent连续执行与原生真实验收

**What to build:** 用户要求持续处理时，Agent按实际剩余图像推进知识版本，遇冲突隔离并保留人审待办，范围耗尽后给出真实结果。

**Blocked by:** 05：人工确认与知识重新核验；07：冻结图组的取消恢复与历史保护

**Status:** in-progress

- [ ] 对应 A01～A16、T01～T03；裸导入独立结束，单组只执行一组，明确完整意图完成对应阶段；无专用挖掘技能或全局流程提示词强制串联。
- [ ] 真实原生Agent从43张合成图按每次20张运行20/20/3，形成V1→V2→V3；后续实传上一版本和新图，不手工串调工具冒充Agent。单组20发布不能提前回复全量完成。
- [ ] 已明确连续范围后只回答“20张”仍保留原范围；先多后少、无预设、明确不用预设、只看一组及末组不足均符合A11，不打印全库ID进模型上下文。
- [ ] 持久化范围/组引用与派生剩余一致；取消后不自行续跑，恢复无重复执行/发布，源变与新增图像不被悄悄算作本链有效覆盖。
- [ ] 固定外部响应在中间组制造规则/整图/局部冲突，验证后继隔离、人审待办跨版本不丢、无可用依据暂停；明确人审及重核验后可沿新版本继续。
- [ ] 真实部署配置MLLM仅用新合成图和隔离库，记录实际能力、输入、证据、版本及终态；模型未发现预设缺陷如实记录，不伪造结论或宣称工业准确率。
- [ ] 原生浏览器完成类型/预设/选图、单组与连续范围、查看进度/冲突、人审、明确重核验、取消恢复和历史定位；明暗/窄屏/2倍字号/键盘/模态关闭通过。
- [ ] 最终按同范围报告已观察、待人审、待重核验、失败/未处理与知识限制；各覆盖口径不混加，知识学习不计模型审计或人审覆盖；已有Labelme/目录导入、正式审计与分项报告定向回归通过。
- [ ] 连续多组包含无冲突的新知识扩充：首组旧条目保留，新判据证据充足则新增，不足则跨组累积后同ID升级；核对实际独立支持、冻结策略、版本差异及页面来源，重复/增强/ROI不得凑数。
