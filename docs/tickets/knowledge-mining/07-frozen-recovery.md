# 07: 冻结图组的取消恢复与历史保护

**What to build:** 用户取消、查看、恢复同一图组时，能区分已观察、已发布和未处理，失败不破坏知识或连续范围。

**Blocked by:** 06：按实际能力分组并完整覆盖图像

**Status:** completed

- [x] 对应 A05、A09～A11、A14；冻结图组、预设、来源、配置、适用人审/冲突快照与发布基线，只原子发布一个公开版本。
- [x] 取消请求态与终态可见，不隐式重启；连接失败、生成超时、结构错误、输出截断分别保留真实原因，不伪造成每张图片异常。
- [x] 关联重试校验冻结输入；源图、预设、人审、配置或头变化拒绝混合恢复；旧契约缺信息只读查看，不猜测或默认补齐。
- [x] 失败、并发、取消无半发布、重复版本或越范围处理；组内局部成功不计本组已发布覆盖，既有观察证据仍可回看。
- [x] 公开链验证取消/超时/重启恢复/变更/并发，页面与DSH读取同一状态；恢复已发布组不再发模型调用，仍运行组不重复启动。
