# 02: 三输入图组挖掘与真实选图

**What to build:** 用户在统一页面或对话选择具体图像及数量，不带知识预设完成良品归纳或异常候选假设，并看到同一作业与结果。

**Blocked by:** 01：统一知识页面与按意图独立触发

**Status:** ready-for-agent

- [ ] 对应 A03、A04、A06、A12、A14；两工具仅暴露可选预设、数量、对应图像，无首批/后续参数，契约和工具参数由单一类型源生成。
- [ ] 只读查询提供真实引用、资格、分页与稳定选择；页面显示目标数、已选数与预览，默认建议10张，可改20或指定数量，候选不足就地反馈。
- [ ] 数量严格一致，拒绝空组、重复引用、跨数据集及不合格来源；不静默修正数量、补图、推断当前知识或扩大到全库。
- [ ] 良品无预设只归纳本组，异常无正常基准只发布provisional假设和限制；页面可查看知识、来源、疑点与失败，不冒充正式审计。
- [ ] 真实数据库/文件经公开HTTP、工具及页面贯通；验证非法输入无模型生成、原标签/人审/Gold不变，相关调用方统一替换后删旧契约分支。
