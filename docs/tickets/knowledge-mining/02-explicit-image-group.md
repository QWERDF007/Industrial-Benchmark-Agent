# 02: 三输入图组挖掘与真实选图

**What to build:** 用户在页面或对话指定数量与真实图像，不带预设归纳一组知识，并看到同一作业、证据和结果。

**Blocked by:** 01：统一知识页面与按意图独立触发

**Status:** ready-for-agent

- [ ] 对应 A03、A04、A06、A12、A14；两个工具仅有可选知识预设、图像数量、对应图像三个业务输入；由同一契约生成工具和客户端，数据集身份由图像解析。
- [ ] 共享查询提供真实引用、资格、分页及稳定选图；页面可预览目标数/已选数，建议10张，可调20或其他数量，候选不足就地反馈。
- [ ] 拒绝空组、数量不符、重复引用、跨集、不合格来源及字符串伪数组；无静默修正、自动补图、隐式预设或扩大全库，非法请求无MLLM生成。
- [ ] 无预设良品只观察本组；异常无正常基准仅整理provisional假设和限制，不把NG标签当视觉真值，不冒充正式模型审计。
- [ ] 页面、原生工具与HTTP经真实库/图像发布同一结果；来源、观察及失败可查，原始标签/人审/Gold不变，统一替换并删除旧隐式全量入口。
