# 03: 可选预设续用与未覆盖查询

**What to build:** 用户给下一组新图选择上一版本，获得可追溯后继知识，并在页面和DSH查询该链真实剩余图像。

**Blocked by:** 02：三输入图组挖掘与真实选图

**Status:** ready-for-agent

- [ ] 对应 A03～A06、A11、A12、A14；10图无预设→5张新图加V1→V2的真实公开链成立；用户明确不用预设时不读取当前头作为学习依据。
- [ ] 良品仅接同类型预设；异常可组合一致的正常基准与异常预设。跨集、重复类型、依赖冲突、证据失效及静默换版均拒绝。
- [ ] 先保存基于冻结旧判据的观察再归纳修订；实际送模输入可证明只处理新图组，旧图仅按需要作比较，继承观察不计本轮新观察。
- [ ] 版本保留继承、增量、反例、拆分/合并/退役；语义父版本与发布头并发基线分离，旧版本不可覆盖。
- [ ] 分页查询按明确范围和版本链返回未覆盖引用及同范围计数，来源指纹变化单列待重核验；其他作业、新增文件不混入本链范围。
- [ ] 公开请求验证父子引用及真实像素，页面可继续选图并编辑预设，刷新后剩余范围不靠对话记忆或另一份可写计数表维持。
