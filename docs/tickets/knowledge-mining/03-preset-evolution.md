# 03: 可选预设续用与未覆盖查询

**What to build:** 用户给下一组新图选择上一版本，获得可追溯后继知识，并在页面和DSH查询该链真实剩余图像。

**Blocked by:** 02：三输入图组挖掘与真实选图

**Status:** completed

- [x] 对应 A03～A06、A11、A12、A14；10图无预设→5张新图加V1→V2的真实公开链成立；用户明确不用预设时不读取当前头作为学习依据。
- [x] 良品仅接同类型预设；异常可组合一致的正常基准与异常预设。跨集、重复类型、依赖冲突、证据失效及静默换版均拒绝。
- [x] 先保存基于冻结旧判据的观察再归纳修订；实际送模输入可证明只处理新图组，旧图仅按需要作比较，继承观察不计本轮新观察。
- [x] 版本保留继承、增量、反例、拆分/合并/退役；语义父版本与发布头并发基线分离，旧版本不可覆盖。
- [x] 分页查询按明确范围和版本链返回未覆盖引用及同范围计数，来源指纹变化单列待重核验；其他作业、新增文件不混入本链范围。
- [x] 公开请求验证父子引用及真实像素，页面可继续选图并编辑预设，刷新后剩余范围不靠对话记忆或另一份可写计数表维持。
- [x] 无冲突新发现按A05区分同义支持、细化修订和独立新判据；证据充分时新增独立ID条目并保留旧知识，不要求先发生冲突或额外人审审批。
- [x] 冻结共享支持策略及实际来源/证据，多个内容来源只是必要条件；重复/增强/同图ROI不凑数，不以组大小或模型置信度替代门槛，未配置策略保持provisional。
- [x] 不足支持跨组保留provisional并累积证据，满足策略后同ID升级；历史证据不冒充本轮观察，无正常基准异常规则仍受A06限制。公开链覆盖新增、去重、不足→补足和冲突阻止升级。
