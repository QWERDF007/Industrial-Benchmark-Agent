# 03: 可选预设与可追溯知识续用

**What to build:** 用户给新图组选择知识预设，看到基于旧知识的观察、后继知识和继承证据；继续选图可沿用刚生成版本。

**Blocked by:** 02：三输入图组挖掘与真实选图

**Status:** ready-for-agent

- [ ] 对应 A03～A06、A11、A12、A14；Agent按上下文决定是否传预设，工具不隐式注入最新知识；用户明确不用预设时遵守。
- [ ] 良品仅接同类型预设；异常可接正常基准、异常预设或一致组合；拒绝跨集、重复类型、依赖冲突、失效或不可用证据，不静默换版。
- [ ] 10图无预设→5张新图加预设生成后继版本；只处理新图组，旧图仅按需要作比较，历史来源不自动全部重发或算作本次新观察。
- [ ] 继承/新增/反例及规则修订可查；语义预设与发布头并发基线分开，无预设生成时不把当前头伪装父知识，历史不可改。
- [ ] 公开操作链捕获实际送模输入并核对版本、来源与图像；页面预设和继续选图与DSH读取同一结果，既有人工修订继续经过证据核验。
