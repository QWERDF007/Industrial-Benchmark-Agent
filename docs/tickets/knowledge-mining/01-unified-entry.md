# 01: 统一知识页面与按意图独立触发

**What to build:** 用户从唯一知识挖掘入口查看良品/异常知识，或在 DSH 分别发起导入、两种挖掘及审计；只导入在完成后停止。必要导航和阶段职责整理在本切片完成。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 对应规格 A01、A02、A12、A14；侧栏仅一个知识挖掘入口，类型切换保留各自数据集配置、选图、版本及作业，既有历史可读。
- [ ] 完整流程仅作为用户按需触发的单一技能，不能注入系统提示词；Agent完成用户要求的全部阶段；裸“导入某目录”不得启动知识、技术审计、模型审计或其重试，缺依赖只解释缺口，不擅自创建其他作业。
- [ ] 页面注册、状态、结果卡和前进后退使用同一导航定义，原双页面分支移除；类型切换不启动/取消作业，键盘焦点可见。
- [ ] 两种挖掘可直接调用既有工具，不要求先加载专用技能；删除重复全量串联指引，工具仍遵守共享领域校验。
- [ ] 公开操作链与原生会话验证独立四阶段及明确组合；裸导入 trace 无后续作业，不能用固定让模型不调用的HTTP脚本代替真实意图验收。
