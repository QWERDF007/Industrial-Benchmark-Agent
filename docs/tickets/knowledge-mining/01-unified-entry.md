# 01: 统一知识页面与按意图独立触发

**What to build:** 用户在唯一知识页面查看良品/异常知识，或在DSH单独发起导入、两种挖掘及模型审计；只执行实际意图，必要的导航和阶段职责整理在本切片完成。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 对应 A01、A02、A12、A14；侧栏仅一个知识入口，类型切换保留各自配置、选图、版本与作业，历史可读；切换及页面刷新不启动/取消作业。
- [ ] 完整组合流程只作为按需技能，不写入全局系统提示词；局部任务直接调用工具，缺依赖只解释缺口，不自行增加昂贵阶段。
- [ ] 裸“导入某目录”及后续独立请求通过公开操作链；真实原生新会话trace与数据库没有额外挖掘、技术审计、模型审计或重试。
- [ ] 结果卡、会话跳转及前进后退定位同一页面；清理旧双页注册和重复指引，复用现有共享控件，不新增导航分叉。
- [ ] 公开测试先失败再实现；原生浏览器验证切换与定位，真实MLLM会话验证局部/组合意图，不用固定HTTP响应替代真实意图验收。
