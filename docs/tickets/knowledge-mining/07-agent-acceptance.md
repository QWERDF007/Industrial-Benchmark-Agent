# 07: Agent连续调用与原生真实验收

**What to build:** 用户在真实DSH中单独发起或明确连续处理图组，按上下文续用知识，并在统一知识页面检查同一结果与后续审计。

**Blocked by:** 04：整图与局部污染核验及复核联动；06：冻结图组的取消恢复与历史保护

**Status:** ready-for-agent

- [ ] 对应 A01～A14、T01～T03；裸导入指令多次新会话均停止于导入，真实轨迹和数据库无额外挖掘/审计；明确完整请求仍能完成对应阶段。
- [ ] 真实Agent依次选择10图无预设、5图带返回知识及可调20图组；连续遍历须有用户范围授权，由持久化版本派生剩余，最后不足数不冒充精确图组。
- [ ] 使用实际部署配置而非固定厂商的MLLM、新合成图和隔离库，验证多图、局部疑点、预设、版本、实际容量和自然终态；不手工串行调工具冒充Agent。
- [ ] 原生浏览器完成统一类型切换、选图、执行、疑点查看、继续选图、取消/重试、结果跳转；明暗/窄屏/2倍字号/键盘/模态焦点通过。
- [ ] Labelme与目录接入、正式审计、人工复核与分项报告定向回归通过；知识学习不计作审计覆盖，不宣称工业准确率；最终清除旧双页面/必经技能/隐式全量分支。
