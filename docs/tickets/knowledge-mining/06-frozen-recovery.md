# 06: 冻结图组的取消恢复与历史保护

**What to build:** 用户从页面或会话取消、查看或恢复同一次图组挖掘，知道已观察、未处理和已发布范围，失败时保留真实证据和历史知识。

**Blocked by:** 05：按实际能力分组并完整覆盖图像

**Status:** ready-for-agent

- [ ] 对应 A05、A09、A10、A12、A14；冻结图组、预设、来源指纹、有效配置标识与发布基线；本次图组只原子发布一个版本。
- [ ] 取消显示请求态与真实终态，不隐式重启；生成超时、格式错误、输出上限及传输失败保留实际调用原因，不伪造成逐图异常裁决。
- [ ] 重试关联原执行且核验冻结输入；来源/预设/配置/头变化拒绝混合恢复；旧契约缺信息只读查看，不能猜成新请求或重试。
- [ ] 失败、并发冲突和取消无半发布或重复写入，继承来源与本次观察计数明确，历史版本与证据可读，改名不无关失效。
- [ ] 公开链验证取消/超时/中断恢复/源变/并发；页面与DSH状态一致，运行或局部观察完成不能声称知识已发布。
