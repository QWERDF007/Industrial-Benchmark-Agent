# 04: 整图与局部冲突证据及隔离

**What to build:** 用户看到新图与知识冲突时，知识条目和图像/ROI均被标记待核实，并可对照真实证据；未受影响知识可继续使用。

**Blocked by:** 03：可选预设续用与未覆盖查询

**Status:** ready-for-agent

- [ ] 对应 A06～A08、A12～A15；从公开挖掘结果创建结构化冲突，关联版本/条目、图像内容指纹、整图或ROI、实际新旧证据和限制，不只存文字说明。
- [ ] 偏离旧知识不等于图片异常或规则错误；记录正常替代解释及位置/光照，覆盖污染、少见正常、反光、局部异常与缺证分支。
- [ ] 冲突与本组发布原子关联；知识和图像双向定位，后继版本保留未解决关联，重复发现追加证据而不重复计覆盖，不因改名/分拆解除限制。
- [ ] 待确认规则不作确定依据，受影响图像/局部不支持对应正常判据，其派生规则不能借多数投票或同内容副本自证；未受影响部分须独立核验。
- [ ] 可用规则继续支持下一组；全部依据受影响或无法隔离时明确暂停，保留剩余与已发布结果，不退回无预设掩盖矛盾。
- [ ] 真实全图、原分辨率覆盖块、外扩20%的标注ROI及模型ROI保持坐标关系；Mask与同范围原图配对，纯定位色不作为外观证据。
- [ ] 公开HTTP固定响应复现跨两轮冲突及无冲突对照；浏览器可查看知识/图像标记、放大全图ROI并跳转同一人工复核上下文。此票不写人工裁决。
