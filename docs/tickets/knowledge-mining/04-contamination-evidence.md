# 04: 整图与局部污染核验及复核联动

**What to build:** 用户在挖掘中发现混入良品的异常图及局部异常，查看正常替代解释和实际全图/ROI，并进入人工复核。

**Blocked by:** 03：可选预设与可追溯知识续用

**Status:** ready-for-agent

- [ ] 对应 A06～A08、A12、A13；先保存基于冻结预设的观察再核验知识增量，整图和局部疑点均有可追溯证据与原图坐标。
- [ ] 污染不得支持受影响正常判据，同图及同内容副本不能独立自证；单例、反光、少见正常和未解决冲突分别保留限制。
- [ ] 全图、原分辨率覆盖块、标注ROI及模型ROI保持来源关系，标注框按宽高外扩20%；Mask与同范围原图配对，不制造假框或把定位色当产品颜色。
- [ ] 异常假设加入独立正常依据后可被支持、反驳或保持缺证，不直接把NG标签变成规则；仅异常预设不等于正常对照。
- [ ] 真实像素/公开HTTP验证污染与非污染对照，页面放大、全图ROI联动及前往人工复核可用，模型工具不能改人审或Gold。
