# 06: 按用户数量联合输入并保留完整证据

**What to build:** 按[规格A08～A11](../../specs/incremental-knowledge-mining.md#a09-不预设模型的能力与容量规划)处理用户明确图组、真实容量及失败后的用户决策。

**Blocked by:** 03：可选预设续用与未覆盖查询

**Status:** completed

- [x] 模型与能力来自实际配置和服务，完整图组携带全图、必要ROI/Mask及比较证据。
- [x] 默认不按固定图数或观察条目预算拆组；显式限制、视觉token、请求体和输出预留不足时保留失败，不降低数量或删减证据。
- [x] 用户回复前不重试或执行下一组；确认降低数量后创建新图组，原失败记录和历史知识保留。
- [x] 容量失败、截断、结构或证据错误不发布知识；实际请求和终态沿公开链可查。

验证入口见[实现与验收索引](../../architecture.md)。
