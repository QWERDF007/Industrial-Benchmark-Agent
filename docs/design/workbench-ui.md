# 工作台 UI 与交互设计

本文件是视觉、页面布局和交互的唯一设计源。领域行为见[规格](../specs/dataset-knowledge-audit.md)，实现入口见[架构索引](../architecture.md)，交付依赖见[票据索引](../tickets/dataset-knowledge-audit.md)。以下为目标设计，尚未实现。

## D01 导航与信息架构

沿用 DSH 原生侧栏及面板注册能力，不嵌套第二个侧栏。插件是宿主入口，以下六项为并列业务入口；两项挖掘位于模型审计之前。

```text
DSH 左侧栏             当前页面
插件（宿主）           标题                         当前数据集 ▾
数据集管理             页面说明仅在空态或有必要时显示
图像浏览               筛选 / 版本 / 执行范围        主操作
挖掘良品知识           ──────────────────────────────────
挖掘不良品知识         页面主体：图像 / 知识 / 作业 / 复核
模型审计               按需展开的证据与技术详情
人工复核
```

| 入口 | 主体与主操作 | 边界 |
| --- | --- | --- |
| 数据集管理 | 数据集列表、当前数据集详情；导入 Labelme | 目录、名称、无标注约定和参考资格在此维护 |
| 图像浏览 | 全数据集图像网格；筛选、选图、大图查看 | 跨流程的样本入口；模型/人审信息只读，跳转相关业务时带样本和来源 |
| 挖掘良品知识 | 正常知识、待核实样本、版本与该类作业；开始挖掘 | 执行、查看和复用良品知识；不是模型审计的子页签 |
| 挖掘不良品知识 | 异常知识、标注核验、版本与该类作业；开始挖掘 | 明示所依据的正常知识版本；缺失时链接良品挖掘 |
| 模型审计 | 范围与知识摘要、审计结果网格、作业、报告；开始审计 | 只消费知识；编辑知识链接对应独立入口 |
| 人工复核 | 待复核队列、大图证据、复核表单、复核记录；提交裁决 | 唯一人工裁决操作与明细入口 |

每页有稳定身份，当前项使用背景、图标与文字共同标识。收窄侧栏时仍有可访问名称和提示，入口顺序不变。页面内“结果 / 作业 / 报告”是局部视图，不重复提供图像浏览或数据集管理页签。

## D02 页面上下文与返回

当前数据集是六页共享的一个状态；数据集 ID 为身份，改名不改变选择或关联。低频上下文与高频表单/图像视口状态分开管理，后台进度更新不重建整页。

| 状态 | 保存与切换规则 |
| --- | --- |
| 当前页、dataset/sample/version/job、业务筛选与页码 | 使用宿主支持的路由/序列化导航能力；刷新与前进后退可恢复，禁止与宿主路由争用 hash |
| 浏览位置与选中图 | 按页面和数据集保留；关闭大图回到原缩略图与滚动位置 |
| 图层、缩放、ROI 锁定 | 同一图的详情切换保留；换图默认适应窗口，保留图层偏好 |
| 人审草稿 | 按 dataset + sample 隔离；切换 ROI、导航与后台刷新均不丢失，明确“草稿未提交” |
| 挖掘/审计作业 | 服务端持久化；切页、刷新、关浏览器均不视为取消 |

切数据集时原数据集作业继续执行，并提示有后台作业；新页只展示所选数据集内容。快速切换时取消旧查询或丢弃过时响应，不能短暂串图、串知识。URL 中不写目录、密钥、完整提示或人审草稿。

## D03 页面布局

### 图像浏览

```text
图像浏览                                         数据集 ▾
[标注 ▾] [模型 ▾] [人审 ▾] [更多筛选] [文件名搜索]
已选条件与清除                                  共 N 张
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│  图像  │ │  图像  │ │  图像  │ │  图像  │
│文件名  │ │文件名  │ │文件名  │ │文件名  │
│模型/人审来源分别显示；标注类别按需显示          │
└────────┘ └────────┘ └────────┘ └────────┘
                                           分页
```

网格不常驻长详情栏。标注有无与类别在同一勾选菜单：同菜单所选项取并集，不同筛选维度取交集；未勾选等于全部。“有标注”覆盖所有类别；不能用重复计数制造结果差异。选择全部范围与当前页选择明确分开，审计默认使用当前筛选的全部结果。

### 数据集管理

桌面为数据集列表 + 当前详情，详情默认显示可编辑名称、图像目录、标注目录、初始良品约定及导入问题。导入在带标题的表单中填写名称并选择两个服务器目录；提交前显示扫描范围，失败保留输入，成功选择新数据集并提供“浏览图像”。数据集详情中的参考缩略图可放大，资格变更与人工 PASS 分别展示。

### 两项知识挖掘

```text
挖掘良品知识 / 挖掘不良品知识                     数据集 ▾
[当前版本 ▾] [候选范围 / 来源摘要]                开始挖掘
覆盖 N / M     待核实 K     来源变化 / 正常版本关系
[知识条目] [待核实 / 标注核验] [版本] [作业]
┌─────────────────────────┬──────────────────────┐
│ 学到的对象、位置、判据   │ 选中条目详情         │
│ 支持状态 / 证据数        │ 支持 / 反对真实图像  │
│ 搜索、按状态筛选         │ 查看大图 / 来源      │
└─────────────────────────┴──────────────────────┘
```

两页共用布局与知识条目组件，内容随知识类型变化。不良页在范围栏展示依据的良品版本；缺失时保留查看历史能力并提供去挖掘的操作。疑似污染与错标不直接显示成已确认不良；条目详情保留正常替代解释和限制。版本选择不会改写正在运行的作业；旧版本可只读回看，界面显示该版本自己的覆盖与来源。

### 模型审计

默认“审计结果”视图，上方紧凑显示筛选范围、良品/不良品知识版本、知识可用性及“开始审计”；没有图像数量或 ROI 预算输入。其他视图为“作业”“报告”。缺少可用良品知识时指向良品挖掘；缺少异常正例时如实提示，可使用已有良品知识作异常筛查，不伪造异常知识。旧数据结果明确显示知识来源不可追溯或未采用当前版本。

作业行显示当前样本、实际阶段、完成/失败/未处理数量与取消入口。详情显示真实批次与错误，点击失败项定位样本。每张完成后更新结果、统计与选中样本的模型摘要；保留筛选、滚动、图像视口和人审草稿。

### 人工复核

默认待复核队列，独立的“复核记录”视图提供明细。打开图像时右侧为复核表单与模型摘要；模型结论不预填成人工裁决。提交后确认已保存的人工决定并推进下一项；失败保留草稿、定位字段错误。草稿可恢复或显式丢弃，不能静默提交。其他页提供“去人工复核”，不再复制可写表单或复核明细。

## D04 共用大图与证据交互

```text
文件名        模型建议 / 人工结果 / 重点疑点       关闭
[可视图层 ▾] [−] [适应] [100%] [+]      [前一张 / 后一张]
┌───────────────────────────────┬────────────────────┐
│                               │ 一句话综合建议     │
│         全图 + 可选 ROI       │ 最多三个重点疑点   │
│                               │ 当前 ROI 真正裁图  │
│     滚轮缩放 / 拖动 / 选区域   │ 依据 / 正常解释    │
│                               │ 追问 Agent / 去复核│
└───────────────────────────────┴────────────────────┘
```

全图、知识来源、参考图、实际裁图调用同一查看器。缩放以鼠标所在图像点为锚；按钮/比例输入以视口中心为锚；适应窗口始终居中，调整比例不跳到左上角。图像尚未加载时显示占位，保留图框尺寸。

可视按钮使用眼睛图标，提示随状态显示“隐藏标注 / 显示标注”，并提供 aria-label 与 pressed 状态；展开菜单分别控制标注、模型候选、覆盖三层。图层状态不能仅靠颜色区分。

悬浮显示短提示；点击/Enter 锁定 ROI，右侧证据与当前框双向联动。重叠区域出现候选列表；拖动超过阈值不触发选择；点击空白取消锁定。键盘列表选择和缩放按钮提供鼠标手势的替代操作。Esc 依次关闭局部菜单、取消锁定、退出查看器；关闭恢复焦点至来源项。触屏通过点按和显式按钮完成操作。

仅展开当前 ROI 正文和真实送模图；显示观察框与外扩裁剪范围差异。样本信息按“图像路径、图像名、UUID”顺序放在独立浅色信息区域，长路径可复制/展开。内部历史样本键不替代面向用户的 UUID。

## D05 视觉系统

采用功能性 Minimalism & Swiss Style：中性色背景、清晰密度、低动效。所有业务页使用同一套 DSH 主题适配 tokens，禁止逐页散落色值、覆盖宿主全局样式或另建主题开关。

| 语义 token / 规则 | 设计约束 |
| --- | --- |
| canvas / surface / surface-muted / viewer | 页面底、主体面板、筛选/信息块、图像底四个可辨层级；明暗主题分别核验 |
| text / text-muted / border / focus | 复用宿主语义；无对应 token 时在一个适配层定义；信息次要不等于降低到不可读 |
| primary / success / warning / danger / neutral | 主操作沿宿主强调色；异常为风险色；知识待核实、技术失败、模型建议、人审各有文字标签 |
| 字号 | 正文 14–16px、辅助 12–13px、页标题 22–24px；路径可等宽，不全局使用等宽字体 |
| 间距 / 圆角 | 4px 微间距，主要 8/16/24px；圆角 8px，控件统一高度 40px，常用图标按钮 44px 点击区域 |
| 面板 / 边框 | 背景层级与留白优先；相邻区域不易分辨时用细分隔线；避免卡片套卡片和密集描边 |
| 状态 / 图标 | 同族 SVG、统一线宽；hover、pressed、focus、disabled、busy 均定义；不用 emoji 作控件图标 |
| 动效 | 控件约 120–180ms，面板约 180–220ms；不移动审图内容，reduced-motion 去除非必要动效 |
| 字体 / 资源 | 沿宿主系统字体及本地资源；证据原图/无损 ROI 不因缩略图优化策略而有损 |

模型结果使用“未审计 / 审计中 / 无明显异常 / 发现疑点 / 证据不足”；人审使用独立裁决标签，技术失败使用错误状态。作业失败不能显示为模型判定不良，模型置信度不能显示为准确率。

## D06 统一反馈与响应式

空数据集给“去数据集管理”，筛选无结果给“清除筛选”，缺知识给对应挖掘入口，证据缺失给具体原因和重新获取途径。加载保留布局；后台刷新失败保留已展示内容并提示刷新失败与时间。表单错误靠近字段，提交多错误时聚焦摘要。取消立即反馈“正在停止”，实际请求未结束前不允许同一作业重复启动。

桌面主操作与数据集选择位置一致，每页只有一个视觉主操作。1280px 及以上知识/复核详情保持约 320–384px，图像占剩余空间；窄视口转为上下布局或可展开详情，不能缩到无法审图。375px 保留全部操作的可达性；导航折叠、筛选换行、详情单独展开，不出现页面级水平滚动。

验收覆盖 1920×1080、1366×768、1280×800、375×812、明暗主题及 200% 文本缩放。正文对比度至少 4.5:1，重要图标/控件边界至少 3:1，焦点清晰且不被固定栏遮挡。进度更新使用一个节流状态播报，不逐 token 抢焦点。

## 设计依据

已实际执行 ui-ux-pro-max 的 design-system（industrial inspection dashboard；operations dashboard，variance 2 / motion 1 / density 8）、UX（sidebar navigation active state；keyboard focus modal）和 React（state shared context）检索。

匹配并采用：Minimalism & Swiss Style、当前导航标识、可恢复导航、焦点可见、共享低频状态和局部表单状态。两次生成均返回营销 Hero 布局，没有匹配到可直接采用的工业工作台布局；上述页面线框为结合现有 DSH 工作台作出的设计。字体、营销布局、入场动画与整套配色不作为项目规范。React 检索标注版本高于当前 React 18，仅采用通用状态设计，不据此升级框架。
