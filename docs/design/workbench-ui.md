# 工作台 UI 与交互设计

本文件是视觉、页面布局和交互的唯一设计源。领域行为见[规格](../specs/dataset-knowledge-audit.md)，实现入口见[架构索引](../architecture.md)，交付依赖见[票据索引](../tickets/dataset-knowledge-audit.md)。实现与验收进度仅见根 WORKLOG.md。

## D01 导航与信息架构

沿用 DSH 原生侧栏及面板注册能力，不嵌套第二个侧栏。插件是宿主入口，以下六项为并列业务入口；两项挖掘位于模型审计之前。

```text
DSH 左侧栏             当前页面
插件（宿主）           标题                         当前数据集 ▾
数据集管理             页面说明仅在空态或有必要时显示
图像浏览               筛选 / 版本 / 执行范围        主操作
挖掘良品知识           ──────────────────────────────────
挖掘不良品知识         页面主体：图像 / 知识 / 作业 / 复核
模型审计               按需展开的证据与技术详情
人工复核
```

| 入口 | 主体与主操作 | 边界 |
| --- | --- | --- |
| 数据集管理 | 数据集列表、当前数据集详情；导入 Labelme | 维护目录、名称、无标注初始约定和扫描问题，不嵌入图像网格 |
| 图像浏览 | 全数据集图像网格；筛选、选图、大图查看、管理良品来源 | 来源资格仅在管理模式维护；图像详情及模型/人审信息只读 |
| 挖掘良品知识 | 正常知识、待核实样本、版本与该类作业；开始挖掘 | 执行、查看和复用良品知识；不是模型审计的子页签 |
| 挖掘不良品知识 | 异常知识、标注核验、版本与该类作业；开始挖掘 | 明示所依据的正常知识版本；缺失时链接良品挖掘 |
| 模型审计 | 范围与知识摘要、审计结果网格、作业、报告；开始审计 | 只消费知识；编辑知识链接对应独立入口 |
| 人工复核 | 待复核队列、大图证据、复核表单、复核记录；提交裁决 | 唯一人工裁决操作与明细入口 |

每页有稳定身份，当前项使用背景、图标与文字共同标识。收窄侧栏时仍有可访问名称和提示，入口顺序不变。页面内“结果 / 作业 / 报告”是局部视图，不重复提供图像浏览或数据集管理页签。

### 各步骤的进度、结果与修改

六个入口始终可进入，不因上一步未完成而禁用整页。缺少执行前提时只禁用依赖该前提的操作，提供前往来源步骤的链接，历史结果仍可查看。会话中的进度卡片可打开对应数据集、作业或版本；页面可以回到发起会话。

| 步骤 | 进度与状态 | 可查阅结果 | 可维护内容与继续方式 |
| --- | --- | --- | --- |
| 数据集管理 | 目录检查/扫描/导入的实际状态、已处理与失败数量；未提供总数时不显示百分比 | 图像及标注数量、类别、导入问题与来源 | 修改名称和无标注约定；调整接入目录后显式重新扫描/导入，保留已有来源记录 |
| 图像浏览 | 当前筛选数量、模型审计与人工复核覆盖；不设浏览完成百分比 | 全图、标注、模型建议及人工结果的独立来源 | 修改筛选、选择范围、可视图层；良品来源由知识页进入管理模式维护 |
| 挖掘良品知识 | 当前阶段、实际处理范围、完成/失败/未处理数量及待核实项 | 正常判据、正常变化、污染疑点、支持/反对证据与版本 | 查看来源摘要并跳转图像浏览管理来源；提出条目修订或核验反馈，重新核验形成后继版本 |
| 挖掘不良品知识 | 同一作业状态展示，并显示依据的良品版本 | 异常判据、标注核验、正常替代解释、限制与真实证据 | 调整异常候选、核验反馈和所依据的良品版本；重新核验形成后继版本 |
| 模型审计 | 逐图完成/失败/未处理、当前阶段、所用冻结版本 | 综合建议、疑点、全图/ROI 证据、覆盖及质量报告 | 修改执行范围、选择知识版本，重审或重试失败/未处理项；人工裁决仍前往人工复核 |
| 人工复核 | 待复核、已提交及剩余数量，草稿单独标记 | 模型依据、人工决定、复核明细与历史 | 修改草稿并提交；更正已提交决定保留历史，已核实反馈可供后续知识挖掘使用 |

页面头部遵循 D07；版本与作业信息在对应局部视图展示，并提供“结果”“作业记录”及该步骤适用的修改入口。侧栏只保留固定业务名称和图标，不把运行、待审计、待复核、技术问题或刷新错误拼进名称。进度与待办数量放在对应页面的轻量摘要及作业记录中；多次运行不可压成一个含混的百分比。每项状态带文字语义，不能只靠颜色或图标。

修改表单区分草稿与已保存内容。保存前展示受影响的下游步骤，保存后显示实际保存结果及“生成新版本 / 使用所选版本重新执行”等明确操作。改名不使知识失效；来源、参考资格、判据或其正常版本关系变化时按实际依赖标记受影响结果。知识文字修订是待核验输入，不能直接变成有证据支持的事实。正在运行的作业继续使用原冻结版本，页面编辑不能热替换其输入；后继执行与旧结果都可回看，不自动串行重跑或覆盖人工裁决。

当前作业完成一张后更新对应结果和计数；切页后仍能重新查询。刷新错误保留上次结果并显示更新时间，不把旧数据显示成实时状态。侧栏、页面、会话共用服务端记录，页面不另外保存流程完成标志。

## D02 页面上下文与返回

当前数据集是六页共享的一个状态；数据集 ID 为身份，改名不改变选择或关联。低频上下文与高频表单/图像视口状态分开管理，后台进度更新不重建整页。

| 状态 | 保存与切换规则 |
| --- | --- |
| 当前页、dataset/sample/version/job、业务筛选与页码 | 使用宿主支持的路由/序列化导航能力；刷新与前进后退可恢复，禁止与宿主路由争用 hash |
| 浏览位置与选中图 | 按页面和数据集保留；关闭大图回到原缩略图与滚动位置 |
| 图层、缩放、ROI 锁定 | 同一图的详情切换保留；换图默认适应窗口，保留图层偏好 |
| 人审草稿 | 按 dataset + sample 隔离；切换 ROI、导航与后台刷新均不丢失，明确“草稿未提交” |
| 挖掘/审计作业 | 服务端持久化；切页、刷新、关浏览器均不视为取消 |

切数据集时原数据集作业继续执行，并提示有后台作业；新页只展示所选数据集内容。快速切换时取消旧查询或丢弃过时响应，不能短暂串图、串知识。URL 中不写目录、密钥、完整提示或人审草稿。

浏览位置实现见[PagePosition](../../apps/iad-harness/src/client/usePagePosition.ts)，来源焦点恢复见[Modal](../../apps/iad-harness/src/client/components/Modal.tsx)。

## D03 页面布局

### 图像浏览

```text
图像浏览                                         数据集 ▾
[标注 ▾] [模型 ▾] [人审 ▾] [更多筛选] [文件名搜索]
已选条件与清除                                  共 N 张
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│  图像  │ │  图像  │ │  图像  │ │  图像  │
│文件名  │ │文件名  │ │文件名  │ │文件名  │
│技术/模型│ │技术/模型│ │技术/模型│ │技术/模型│
└────────┘ └────────┘ └────────┘ └────────┘
                                           分页
```

网格不常驻长详情栏。标注有无与类别在同一勾选菜单：同菜单所选项取并集，不同筛选维度取交集；未勾选等于全部。“有标注”覆盖所有类别；不能用重复计数制造结果差异。选择全部范围与当前页选择明确分开，审计默认使用当前筛选的全部结果。

卡片采用固定 4:3 图框、两行信息：文件名、并排的技术分与模型分，图框与文本顶端对齐；保持原图比例，不裁掉检查内容。左上角仅一个无文字的颜色方块；悬浮、键盘聚焦或点击只提示模型状态，以及已有的人工复核结果，不重复文件名、分数或长说明，Esc/外部点击关闭。两项分数各自与标签同行，并排放在文件名下；放大文本或窄空间允许换行以保留完整数值；未审计显示“—”，模型分数沿用现有可疑度含义，不标成准确率。卡片不再追加结论、技术问题长文字或多色文字行。来源标记与选框仅在管理模式显示。完整文件名仍可通过可访问名称和悬浮提示获取。

筛选栏常驻标注、模型、人审和搜索；技术质量、良品来源、排序收进“更多筛选”，生效条件可见且可清除。“良品来源”支持候选/非候选筛选；来源管理由“挖掘良品知识”的“管理来源”进入，图像浏览不放“管理良品来源”按钮；管理模式才显示选框、来源标记和批量操作，提供完成返回操作。图像详情仅查看图片和信息，不放模型审计、人工复核跳转或良品来源编辑按钮；来源变更统一在管理模式中勾选后提交；批量作用范围明确区分当前页与筛选全部，提交后显示实际结果。候选来源不等于人工确认良品。

### 数据集管理

桌面数据集卡片网格占主要空间，右侧为窄幅所选数据集详情，栏宽复用图像工作区规则；两侧面板背景铺满剩余工作区高度并底部对齐，内容从顶部排列，内容较多时可滚动；窄屏按内容高度上下排列。数据集管理页头仅保留标题，不显示数据集选择、刷新和概况统计；由卡片选择数据集，操作成功后同步更新列表与详情。卡片仅展示可编辑名称、图像数量与标注数量，数量以真实导入样本和标注对象计数。点击卡片选择并更新右侧，点击名称处的编辑按钮原位修改；卡片与详情复用同一个名称编辑器和保存接口；回车或点击空白后对比去除首尾空白的新旧文本，仅有变化时保存一次，无变化直接退出，Esc 取消。编辑时仅显示输入框，错误保留输入；回车与取消恢复原入口焦点，失焦保存保留用户的新焦点，成功后所有名称投影同步。详情按名称、数量、服务器目录和导入约定分组，目录保存通过显式“保存并扫描”执行。详情在名称下一行显示数据集 ID。卡片右上角提供与编辑同尺寸的无边框删除图标，点击后弹窗确认，默认聚焦取消；确认删除数据集及其所属项目记录，保留原始图像和标注文件。存在执行中作业时阻止删除并提示先结束作业；失败保留弹窗与错误，成功同步选择与列表，删除后焦点回到添加入口。添加数据集打开表单弹窗，填写数据集名称、服务器图像目录和标注目录；提交前显示扫描范围，失败保留输入，成功选择新数据集。图像浏览使用侧栏入口，良品来源管理遵循本节“图像浏览”，不在详情复制网格。

卡片焦点依据：[Fluent UI 官方卡片](https://fluent2.microsoft.design/components/web/react/core/card/usage)、[对应 GitHub 组件入口](https://github.com/microsoft/fluentui/blob/master/packages/react-components/react-card/library/src/components/Card/Card.tsx)。行内编辑参考 [Blueprint GitHub 实现](https://github.com/palantir/blueprint/blob/develop/packages/core/src/components/editable-text/editableText.tsx)。组件入口见[DatasetManager](../../apps/iad-harness/src/client/components/DatasetManager.tsx)、[名称编辑器](../../apps/iad-harness/src/client/components/DatasetName.tsx)。

### 两项知识挖掘

```text
挖掘良品知识 / 挖掘不良品知识                     数据集 ▾
[当前版本 ▾] [候选范围 / 来源摘要]                开始挖掘
覆盖 N / M     待核实 K     来源变化 / 正常版本关系
[知识条目] [待核实 / 标注核验] [版本] [作业]
┌─────────────────────────┬──────────────────────┐
│ 学到的对象、位置、判据   │ 选中条目详情         │
│ 支持状态 / 证据数        │ 支持 / 反对真实图像  │
│ 搜索、按状态筛选         │ 查看大图 / 来源      │
└─────────────────────────┴──────────────────────┘
```

两页共用布局与知识条目组件，内容随知识类型变化。不良页在范围栏展示依据的良品版本；缺失时保留查看历史能力并提供去挖掘的操作。疑似污染与错标不直接显示成已确认不良；条目详情保留正常替代解释和限制。版本选择不会改写正在运行的作业；旧版本可只读回看，界面显示该版本自己的覆盖与来源。

### 模型审计

默认“审计结果”视图，上方紧凑显示筛选范围、良品/不良品知识版本、知识可用性及“开始审计”；没有图像数量或 ROI 预算输入。其他视图为“作业”“报告”。缺少可用良品知识时指向良品挖掘；缺少异常正例时如实提示，可使用已有良品知识作异常筛查，不伪造异常知识。旧数据结果明确显示知识来源不可追溯或未采用当前版本。

共同作业状态与恢复操作见 [JobCard](../../apps/iad-harness/src/client/components/JobCard.tsx) 和 [JobRunner](../../python/iad_core/workbench/jobs.py)；停止语义参考 [Celery 官方 worker 文档](https://github.com/celery/celery/blob/main/docs/userguide/workers.rst#revoke-revoking-tasks)。

待审计版本查询与选择见 [useKnowledge](../../apps/iad-harness/src/client/useKnowledge.ts) 和 [AuditSetup](../../apps/iad-harness/src/client/components/AuditSetup.tsx)，选择上下文见 [Workspace](../../apps/iad-harness/src/client/workspace.tsx)。

作业行显示当前样本、实际阶段、完成/失败/未处理数量与取消入口。详情显示真实批次与错误，点击失败项定位样本。每张完成后更新结果、统计与选中样本的模型摘要；保留筛选、滚动、图像视口和人审草稿。

### 人工复核

默认待复核队列，独立的“复核记录”视图提供明细。打开图像时右侧为复核表单与模型摘要；模型结论不预填成人工裁决。提交后确认已保存的人工决定并推进下一项；失败保留草稿、定位字段错误。草稿可恢复或显式丢弃，不能静默提交。其他页提供“去人工复核”，不再复制可写表单或复核明细。

提交结果未确认时保留原草稿和提交身份，刷新后仍可重试确认；确认前不以另一份内容替换该次提交。更正已确认裁决形成新记录，历史决定和复核人保持可查阅。

## D04 共用大图与证据交互

```text
文件名        模型建议 / 人工结果 / 重点疑点       关闭
[可视图层 ▾] [−] [适应] [100%] [+]      [前一张 / 后一张]
┌───────────────────────────────┬────────────────────┐
│                               │ 一句话综合建议     │
│         全图 + 可选 ROI       │ 最多三个重点疑点   │
│                               │ 当前 ROI 真正裁图  │
│     滚轮缩放 / 拖动 / 选区域   │ 依据 / 正常解释    │
│                               │ 追问 Agent / 去复核│
└───────────────────────────────┴────────────────────┘
```

全图、知识来源、参考图、实际裁图调用同一查看器。缩放以鼠标所在图像点为锚；按钮/比例输入以视口中心为锚；适应窗口始终居中，调整比例不跳到左上角。图像尚未加载时显示占位，保留图框尺寸。

视口生命周期见[ImageViewer](../../apps/iad-harness/src/client/components/ImageViewer.tsx)，当前筛选与分页的前后图见[SampleNavigation](../../apps/iad-harness/src/client/useSampleNavigation.ts)。生命周期分层参考[成熟查看器的 ZoomController](https://github.com/igordanchenko/yet-another-react-lightbox/blob/master/src/plugins/zoom/ZoomController.tsx)；焦点恢复参考[HTMLElement.focus](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/focus)。

可视按钮使用眼睛图标，提示随状态显示“隐藏标注 / 显示标注”，并提供 aria-label 与 pressed 状态；展开菜单分别控制标注、模型候选、覆盖三层。图层状态不能仅靠颜色区分。

悬浮显示短提示；点击/Enter 锁定 ROI，右侧证据与当前框双向联动。重叠区域出现候选列表；拖动超过阈值不触发选择；点击空白取消锁定。键盘列表选择和缩放按钮提供鼠标手势的替代操作。Esc 依次关闭局部菜单、取消锁定、退出查看器；关闭恢复焦点至来源项。触屏通过点按和显式按钮完成操作。

仅展开当前 ROI 正文和真实送模图；显示观察框与外扩裁剪范围差异。样本信息按“图像路径、图像名、UUID”顺序放在独立浅色信息区域，长路径可复制/展开。内部历史样本键不替代面向用户的 UUID。

追问与冻结检视返回的实现见[InspectionQuestion](../../apps/iad-harness/src/client/components/InspectionQuestion.tsx)、[InspectionSession](../../apps/iad-harness/src/client/inspection-session.ts)；宿主会话作用域参考 [DSH 官方会话控制](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-conversation/src/client/service.ts)与[导航](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-workspace/src/client/navigation.ts)。

会话结果入口见[SessionResult](../../apps/iad-harness/src/client/components/SessionResult.tsx)与[页面协议](../../apps/iad-harness/src/shared/navigation.ts)，发起会话返回见[JobCard](../../apps/iad-harness/src/client/components/JobCard.tsx)。原生工具视图注册参考[DSH 官方工具展示](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-tool/src/client/apply.ts)。

## D05 视觉系统

采用功能性 Minimalism & Swiss Style：中性色背景、清晰密度、低动效。所有业务页使用同一套 DSH 主题适配 tokens，禁止逐页散落色值、覆盖宿主全局样式或另建主题开关。

| 语义 token / 规则 | 设计约束 |
| --- | --- |
| canvas / surface / surface-muted / viewer | 页面底、主体面板、筛选/信息块、图像底四个可辨层级；明暗主题分别核验 |
| text / text-muted / border / focus | 复用宿主语义；无对应 token 时在一个适配层定义；信息次要不等于降低到不可读 |
| primary / success / warning / danger / neutral | 产品主操作使用统一蓝色，在唯一主题适配层定义并分别核验明暗主题，不继承黑色品牌值；宿主背景与文字保持适配。异常为风险色；知识待核实、技术失败、模型建议、人审各有文字标签 |
| 字号 | 正文 14–16px、辅助 12–13px、页标题 22–24px；路径可等宽，不全局使用等宽字体 |
| 间距 / 圆角 | 4px 微间距，主要 8/16/24px；圆角 8px，控件统一高度 40px，常用图标按钮 44px 点击区域 |
| 面板 / 边框 | 背景层级与留白优先；相邻区域不易分辨时用细分隔线；避免卡片套卡片和密集描边 |
| 状态 / 图标 | 同族 SVG、统一线宽；hover、pressed、focus、disabled、busy 均定义；不用 emoji 作控件图标 |
| 动效 | 控件约 120–180ms，面板约 180–220ms；不移动审图内容，reduced-motion 去除非必要动效 |
| 字体 / 资源 | 沿宿主系统字体及本地资源；证据原图/无损 ROI 不因缩略图优化策略而有损 |

模型结果使用“未审计 / 审计中 / 无明显异常 / 发现疑点 / 证据不足”；人审使用独立裁决标签，技术失败使用错误状态。作业失败不能显示为模型判定不良，模型置信度不能显示为准确率。

## D06 统一反馈与响应式

空数据集给“去数据集管理”，筛选无结果给“清除筛选”，缺知识给对应挖掘入口，证据缺失给具体原因和重新获取途径。加载保留布局；后台刷新失败保留已展示内容并提示刷新失败与时间。表单错误靠近字段，提交多错误时聚焦摘要。取消立即反馈“正在停止”，实际请求未结束前不允许同一作业重复启动。

桌面主操作与数据集选择位置一致，每个独立任务区只有一个视觉主操作；需要步骤统计的页面以轻量摘要行展示当前步骤适用的数据，头部规则见 D07。1280px 及以上知识/复核详情保持约 320–384px，图像占剩余空间；窄视口转为上下布局或可展开详情，不能缩到无法审图。375px 保留全部操作的可达性；导航折叠、筛选换行、详情单独展开，不出现页面级水平滚动。

验收覆盖 1920×1080、1366×768、1280×800、375×812、明暗主题及 200% 文本缩放。正文对比度至少 4.5:1，重要图标/控件边界至少 3:1，焦点清晰且不被固定栏遮挡。进度更新使用一个节流状态播报，不逐 token 抢焦点。

## D07 组件与操作位置

| 组件 / 区域 | 统一交互与位置 |
| --- | --- |
| 按钮 | 主操作为蓝色实底，次操作为中性描边，普通操作默认可辨认，不使用悬浮后才显现的文字按钮；标签页与图像卡片按其选择语义呈现，危险操作使用明确危险语义；同组等高，忙碌时保留尺寸并阻止重复提交 |
| 页面头部 | 数据集管理仅标题，其余页面左侧标题与简短统计、右侧数据集选择与轻量刷新；页面执行操作位于其配置区右侧，避免重复启动按钮 |
| 数据集操作 | “添加数据集”放列表标题右侧；名称编辑遵循“数据集管理”的行内规则；保存并扫描放目录组末尾，不把不同保存语义混成一个按钮 |
| 知识 / 审计 | 版本、范围与主操作组成紧凑配置栏；模型等低频选项按需展开；“管理来源”跳转图像浏览并保留来源筛选与返回上下文 |
| 选择控件 | 简单单选保留原生 select，多选使用带复选框的浮层；统一触发器、选中态、焦点、禁用态，字段有可见标签 |
| 多选浮层 | 点击外部、再次点击触发器或 Esc 关闭；打开其他浮层关闭旧浮层；勾选保持展开，已选立即生效且关闭不丢失；Esc 返回触发器焦点，外部点击不抢走目标焦点，Tab 可离开且不形成焦点陷阱 |
| 勾选 / 单选 | 多选用复选框，互斥裁决用单选；整行标签可点击，勾选清晰。自动保存的布尔约定保留原语义并显示保存反馈 |
| 对话框 / 表单 | 标题和右上角关闭图标固定在顶部，内容可滚动；点击遮罩或 Esc 关闭，拖动始于内容区时不误关，关闭恢复来源焦点并保留筛选/滚动/人审草稿；取消在前、主操作在后，位于表单底部右侧；错误邻近字段，提交后聚焦相应结果 |
| 人工复核 | 裁决与备注组成一个表单，提交靠近表单末尾；空间不足回归文档流，不能遮挡图像、错误或键盘焦点；保留草稿及唯一人工写入口 |

所有共享控件复用一个主题适配层与组件实现，页面、弹窗和 Agent 结果卡共用 [controls](../../apps/iad-harness/src/client/controls.ts)；卡片布局由 [SampleCard](../../apps/iad-harness/src/client/components/SampleCard.tsx) 封装，提示由 [Tooltip](../../apps/iad-harness/src/client/components/Tooltip.tsx) 复用 Floating UI；浮层关闭和焦点策略在共享浮层中处理，不逐页添加 document 事件补丁。验收通过公开工作台及隔离的真实 DSH 宿主操作，覆盖外部点击、Esc、切换浮层、连续多选、来源管理、返回和后台刷新，保持真实 SQLite/图像/作业依赖，仅替换外部 MLLM HTTP。

## 设计依据

连续复核参考 [Label Studio 的队列与 Quick View 行为](https://labelstud.io/guide/labeling.html)及其[GitHub 源文档](https://github.com/HumanSignal/label-studio/blob/develop/docs/source/guide/labeling.md)；本项目以 D03 定义队列提交推进与历史回看。

已实际执行 ui-ux-pro-max 的 design-system（industrial inspection dashboard；operations dashboard，variance 2 / motion 1 / density 8）、UX（sidebar navigation active state；keyboard focus modal）和 React（state shared context）检索。

匹配并采用：Minimalism & Swiss Style、当前导航标识、可恢复导航、焦点可见、共享低频状态和局部表单状态。两次生成均返回营销 Hero 布局，没有匹配到可直接采用的工业工作台布局；上述页面线框为结合现有 DSH 工作台作出的设计。字体、营销布局、入场动画与整套配色不作为项目规范。React 检索标注版本高于当前 React 18，仅采用通用状态设计，不据此升级框架。

步骤反馈补充检索 `background task progress feedback`，采用命中的 Progress Indicators 建议。对照 [LangGraph 官方人工介入文档](https://docs.langchain.com/oss/python/langgraph/interrupts)的持久化身份与恢复语义，作为交互参考，执行仍复用 DSH 与本项目作业。[Open Agent Platform](https://github.com/langchain-ai/open-agent-platform) 官方仓库已声明弃用，不作为新增依赖或实施模板。

检视器交互依据：[W3C 悬浮提示模式](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)、[对应 GitHub 源码](https://github.com/w3c/aria-practices/blob/main/content/patterns/tooltip/tooltip-pattern.html)、[d3-zoom 的缩放锚点实现](https://github.com/d3/d3-zoom/blob/main/src/zoom.js)。

组件参考：[Floating UI 的关闭交互](https://floating-ui.com/docs/useDismiss)及其[GitHub 实现](https://github.com/floating-ui/floating-ui/blob/master/packages/react/src/hooks/useDismiss.ts)、[Carbon 按钮变体源码](https://github.com/carbon-design-system/carbon/blob/main/packages/react/src/components/Button/Button.tsx)。技能检索未找到直接匹配的外部点击关闭或信息渐进展示条目；键盘搜索命中 Web Keyboard Navigation，信息层级采用技能 quick-reference 的 content-priority、compact-label-overflow 与 progressive-disclosure 通用规则，不将无关标题换行结果用作设计依据。

图框布局参考 [MDN button 默认布局](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button)与 [React Photo Album](https://github.com/igordanchenko/react-photo-album) 的响应式布局选择；本项目采用等尺寸网格，共用样式入口见[架构索引](../architecture.md)。
