# 可选知识预设的图组知识挖掘方案

## 目标与现有入口

用户在 DSH 会话分别触发导入数据、良品知识挖掘、异常知识挖掘、模型审计，也可明确要求组合执行。单步意图只执行该步及必要的只读查询，不擅自启动其他挖掘或审计。

已有工具注册见[数据集与审计工具](../../apps/iad-harness/src/server/workbench-tools/index.ts)、[知识工具](../../apps/iad-harness/src/server/knowledge/index.ts)。现有容量拆分和知识续写入口分别见[挖掘](../../python/iad_core/knowledge/mining.py)、[作业编排](../../python/iad_core/knowledge/service.py)；本方案调整这两个模块的职责与调用契约，不新建平行挖掘链。

数据导入、原始标签、人审、图像证据及报告继续遵循[统一接入规格](dataset-import.md)。本方案定义挖掘工具、可选预设、显式图组与统一知识挖掘页面交互；异常工具无良品基准时的候选归纳语义以本方案为准。

## 工具契约

沿用 `knowledge_mine_normal`、`knowledge_mine_defect` 两个直接工具，去掉启动它们之前必须加载专用技能的要求。专用技能中的领域约束归入共享契约和领域校验，移除重复的两套启动指引；DSH 通用技能机制保持其原职责。

两个工具仅暴露以下三个业务输入：

| 输入 | 语义 |
| --- | --- |
| `knowledge_preset` | 可省略的知识预设引用。为空表示本次不使用旧知识；非空可携带相关良品、异常知识版本引用。预设存在与否由该值表达，不另设布尔开关。 |
| `image_count` | 本次明确输入的原始图像数量，正整数；不是整个数据集的处理上限。 |
| `images` | 对应数量的已导入样本引用；由 Agent 或页面从共享查询取得，不要求用户上传或粘贴图像编码。 |

校验 `image_count == len(images)`，禁止重复样本引用、跨数据集混用或不合格来源；重复内容仍按内容哈希识别，不能充当多个独立支持。数据集身份从样本引用解析，模型及会话来源由项目配置和宿主注入。预设必须与本图组属于同一数据集，工具不得自行读取“最新知识”代替未提供的预设。

不设首批/后续批次字段、隐式全数据集扫描或后台自动遍历剩余来源。Agent 根据用户指令、会话上下文和已持久化版本，决定图组数量与是否提供预设；每次调用的作用范围始终是传入图组。

| 工具与输入 | 输出语义 |
| --- | --- |
| 良品挖掘，无预设 | 联合归纳候选图像的结构、位置、纹理、光照与允许变化，记录整图及局部疑点。来源资格不等于正常真值。 |
| 良品挖掘，有预设 | 先依据冻结预设观察本图组，再核验新增支持、反例和正常变化，形成知识增量及后继版本。 |
| 异常挖掘，无预设 | 从异常候选中提炼可见外观、局部假设与限制；没有正常比较基准时，相关判据保留待验证，不能冒充已核验异常知识。 |
| 异常挖掘，有预设 | 结合显式提供的良品基准及/或已有异常知识核验、补充、修订；缺少独立正常对照时继续保留限制。 |

工具返回同一持久化作业的 `run_id`；终态结果提供新知识版本引用、本次处理范围、知识变化及逐图/局部疑点。下一次是否继续、是否使用该版本，由 Agent 或页面用户决定。开始挖掘不代表已经完成模型审计。

## 单次图组执行

1. 冻结预设版本、本次样本、内容指纹和来源资格；只读查询与页面共用[查询入口](../../python/iad_core/workbench/query.py)和[资格入口](../../python/iad_core/knowledge/sources.py)。DSH 需要显式图组时，将现有样本查询投影为只读工具，支持分页及从指定知识版本派生的已覆盖范围，避免让 Agent 编造文件名、样本 ID 或凭对话文本记全部处理清单。
2. 无预设时联合观察本组真实图像；有预设时传入冻结知识与本组新图。历史知识保留原证据来源，需要比较或修订时读取相关历史原图/ROI，不把全部旧来源自动并入本次新图范围或每次全部重发。
3. 同一来源的全图、真实区域或原分辨率覆盖块尽量一起送入 MLLM，结合位置、结构、光照分析；需要时追加模型提议 ROI。真实标注区域继续按框宽高各外扩 20%，无区域标注不生成假框。
4. 先记录基于旧知识与当前图像的观察，再提出知识修订；新增规则不得成为认定其自身来源正常的唯一理由。单图或同内容副本形成的模式保留单例限制，不能冒充跨来源共识。
5. 对整图和局部疑点给出支持异常、正常替代解释或证据不足，保留真实证据及坐标。疑似污染不得支持受影响的正常判据；其他正常部位能否支持其他判据按位置和证据分别核验。少见正常外观不能仅因少见就判异常。
6. 发布不可变后继知识，区分继承的历史证据与本轮实际观察。保留未解决疑点及规则继承/修订关系；预设依赖、输入变化或并发发布冲突均显式报告，不静默换版或覆写旧版本。

已完成图组中的新发现可用于之后的知识挖掘，但不自动改写原始 OK/NG、人审或 Gold。若后续知识变化影响旧图结论，标示需回看范围；没有重新观察的旧图不能标为已按新知识核验。人工裁决仍只在人工复核完成。

## 容量与失败语义

`image_count` 只数原始图像。实际送模还可能包含各图 ROI、原图/Mask 配对、必要历史比较图、预设知识和输出空间；页面及作业记录应区分来源图数与实际视觉输入数。

复用[模型容量预检](../../python/iad_core/workbench/vision.py)，核对实际含图 token、输出预留及服务声明的每请求图像上限。上下文足够时整组多图一次输入；不足时只在本次给定图组内部按容量分组，保留完整覆盖与真实证据关联，记录实际分组，不能悄悄少处理图像或降低细节来凑数。跨组归纳不得伪称重新观察未发送的图像，涉及疑点或规则变化须带相关真实图像核验。

若最小必要全图/局部证据也无法容纳，或者模型输出不完整，明确返回失败或缺证，不发布假成功。256K 等标称上下文不能直接转换成固定可用图数，更不能保证知识质量或检出所有污染。

沿用[作业](../../python/iad_core/workbench/jobs.py)、[知识发布](../../python/iad_core/knowledge/repository.py)及既有取消/重试链；本次图组原子发布一个知识版本，容量子步骤不另造公开版本和独立状态机。取消保留观察证据，失败不改写已有知识；重试核验本次冻结图组与预设，不混入新的样本或自动改用新知识。明确移除旧的“续写必定重看全部历史来源”逻辑，不保留并行旧模式。

## DSH 与页面交互

DSH 可分别表达：

- “仅导入服务器目录 /data1/data/xxx。”
- “选择 50 张良品候选，不带知识预设，挖掘良品知识。”
- “选择尚未处理的 10 张，结合刚才返回的良品知识继续挖掘。”
- “选择 10 张异常候选，结合已有良品和异常知识挖掘异常知识。”
- “使用指定知识版本，对当前筛选图像做模型审计。”

这些指令由 Agent 转换成对应工具调用。“先 50 张，再每次 10 张直到完成”属于会话编排：Agent 查询真实剩余范围、依次调用同一工具、传递返回的知识引用并报告实际覆盖；不是挖掘工具的新参数或另一个学习引擎。用户只要求一组时不继续遍历。

侧栏将“挖掘良品知识”和“挖掘不良品知识”合并为唯一的“知识挖掘”入口，顺序为数据集管理、图像浏览、知识挖掘、模型审计、人工复核。

页面顶部以“良品 / 异常”切换挖掘类型，使用同一个页面与配置组件，调用对应的独立工具。切换类型不启动或取消作业；按数据集与知识类型分别保存预设、图像数量、选图、查看版本、筛选和作业选择，避免串用结果或丢失未提交输入。

知识条目、疑点、版本及作业记录在同页查看，并明确所属知识类型；可以从良品疑点查看关联异常知识。知识版本、来源资格及异常知识的良品依据继续分别建模，页面合并不合并其领域事实。

统一页面复用相同工具契约：

| 区域 | 交互 |
| --- | --- |
| 执行配置 | 选择知识预设或“不使用”；填写本次图像数量；选择图像并预览。异常模式可在预设中组合良品基准和已有异常知识；不设首批/后续控件。 |
| 图像选择 | 复用图像浏览筛选和等尺寸卡片，显示已选数量/目标数量。支持从筛选结果选取指定数量及手动调整；候选不足或数量不符时就地提示，不静默补图、重复或改数。 |
| 执行与进度 | 主操作为“开始挖掘”，运行后显示本次范围、实际进度、取消和重试。页面与会话打开相同作业，不另建页面执行循环。 |
| 结果与继续 | 查看知识条目、变化、版本及整图/局部疑点；图像可放大并联动 ROI，疑点可进入人工复核。点击“继续选择图像”时可沿用刚生成知识作为可编辑预设，清空本次图组并允许修改数量。 |

沿用当前主题、共享按钮/选择器/表单/模态和焦点恢复。输入有明确标签，错误靠近对应字段；加载、成功和失败有反馈。统一维护[导航定义](../../apps/iad-harness/src/shared/navigation.ts)、[页面注册](../../apps/iad-harness/src/client/index.ts)、[工作台状态](../../apps/iad-harness/src/client/workspace.tsx)及会话结果跳转；项目内知识结果卡、作业链接和前进/后退统一定位到“知识挖掘＋类型＋数据集＋版本/作业”。移除原两个页面入口和重复导航分支，不保留隐藏副本。现有知识与作业历史数据保留，可在统一页面按类型查阅。

页面沿用当前颜色和组件，不堆叠统计卡片；类型切换具备明确选中状态及键盘操作，窄屏自然换行。

## 实现与验收约束

Pydantic 继续是请求、预设引用和返回结果的唯一类型源，生成 TypeScript、工具参数及页面契约。将图组解析、容量规划、可选预设与污染核验封装在共享知识模块；Agent 和页面只决定输入，不各自写一套学习或资格逻辑。

开发前确认以下公开操作链测试范围；延续[统一接入测试边界](dataset-import.md#testing-decisions)，真实 HTTP/Python bridge、SQLite、图像文件，只有更深层外部 MLLM HTTP 可替换。

| 范围 | 验收条件 |
| --- | --- |
| 独立触发 | 四步骤能分别触发；两项知识工具无需先调用技能；单步请求不擅自执行完整流水线。 |
| 三输入契约 | 有/无预设均显式；数量与图组严格一致，拒绝重复/越权范围/不合格来源；没有首批、后续参数。 |
| 知识续用 | 50 图无预设得到 K1，10 张新图带 K1 得到 K2，再以不同数量续用；检查真实送模内容，旧图不自动全部重发，未传预设时无隐式知识注入。 |
| 污染与正常变化 | 错标整图、局部异常、反光和少见正常变化分别有可追溯判断；疑点不作为受影响正常规则支持，不由自身或同内容副本独立自证。 |
| 异常候选 | 无基准归纳只形成待验证假设；显式加入良品基准后按真实证据核验，支持、反驳和不足分别保留。 |
| 容量与历史 | 真实 token 边界、每请求图数限制、全图/ROI配对及组内完整覆盖；失败无误发布，取消/恢复/源变/并发冲突不混输入。 |
| 页面与会话 | 侧栏只有一个知识挖掘入口；良品/异常切换分别保留输入与结果，选择预设/数量/图组、放大疑点、继续选图及进度/取消/重试可用。会话结果定位正确类型、数据集和版本/作业，浏览器前进/后退、明暗、窄屏及键盘操作一致。 |
| 真实环境 | 真实 DSH 会话独立触发与连续调用；新合成图及隔离库验证真实 MLLM 图像、结构、版本、局部证据和终态。不将容量可容纳误作工业准确率保证。 |

本方案不新增模型训练、特征学习后端、自动人审或独立准确率/加权质量总分。模型审计仍显式冻结选定知识并覆盖指定范围；知识挖掘结果不代替正式审计覆盖统计。

## 参考依据


以下均为作者或维护方的一手资料；检索日期为 2026-10-21。所述“按图组输入、通过可选预设持续更新知识”是本项目需验证的工程设计，不是这些研究已经证明可靠的组合。

| 来源 | 可借鉴的依据 | 适用边界 |
| --- | --- | --- |
| [Qwen3-VL 官方实现](https://github.com/QwenLM/Qwen3-VL#quickstart) | 同一消息可包含多张图和文本；处理器可控制单图像素预算，影响视觉 token；文档给出 256K 上下文配置。 | 多图和长上下文支持不等于任意 50 张原分辨率图都能放入，也不能保证细小异常识别效果。这是 Qwen3-VL 资料，不能据此认定既有 Qwen3.8 服务的实际参数。 |
| [vLLM 多模态输入官方文档](https://docs.vllm.ai/en/latest/features/multimodal_inputs/) | 提供一条提示包含多图的调用方式；示例分别配置 `limit_mm_per_prompt` 与 `max_model_len`。 | 图像数量限制、视觉 token、知识文本和输出空间需要共同满足实际服务约束；不能只用上下文标称长度推断可用图数。 |
| [MMAD 作者仓库](https://github.com/jam-cc/MMAD) | MLLM 工业异常评测支持调整提示中的正常参考图数量；提供专家在大模型辅助下整理的正常特征、异常分类与类别知识。 | 可借鉴“实际参考图＋结构化领域知识”的输入与评测；其专家参与的知识不等于模型能无监督、自更新地产生正确知识，也未提供本项目所需的逐批来源隔离保证。 |
| [AnomalyGPT 作者实现](https://github.com/CASIA-IVA-Lab/AnomalyGPT) | 结合正常参考、异常描述与局部定位；通过视觉文本特征匹配解码器和提示学习器提供细粒度信息。 | 它采用专门训练、解码器和提示学习，不能直接当作通用 API MLLM 的提示词方案，更不能据此承诺仅增加正常图数量便能获得同等定位能力。 |
| [MuSc 作者实现](https://github.com/xrli-U/MuSc) | 在含正常与异常的无标签图像池中，利用正常局部通常具有更多相似邻居的特点进行跨图互评分，并结合局部邻域与图像级重评分。 | 这是视觉特征方法，非 MLLM 增量知识方案。可借鉴跨样本证据核验；重复异常、多种正常外观及相似性条件仍需实际评测，不能把模型自己认可的来源当成独立真值。 |

这些来源支持多图输入、图文知识和局部证据的组合方向；未建立“批量越大，知识必然越合理”或“用新知识核验其自身来源即可排除污染”的结论。正常池中的整图、局部疑点及知识增量应保留可回溯证据，并通过本项目的独立验收验证效果。
