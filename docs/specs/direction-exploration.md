# 良品与异常联合方向探索

本页定义独立方向探索的新增行为。既有知识挖掘、候选资格、人工边界和输入冻结沿用[知识挖掘规格](incremental-knowledge-mining.md)；外部依据见[资料索引](../research/direction-exploration.md)。

## 用户链路

选择同一数据集的一组候选良品与一组候选异常图 → MLLM 同时观察并提出检查方向 → 用户查看证据并调整 → 知识挖掘勾选采用 → 按所选方向挖掘知识。

侧栏顺序：数据集管理、图像浏览、方向探索、知识挖掘、模型审计、人工复核。方向探索可独立执行，不依赖已有知识版本。

## 验收行为

1. **独立技能与页面**：注册 DSH 技能 `explore-inspection-directions`，可在会话中明确要求探索检查方向；页面与技能操作同一作业、结果和数据集。导入、探索、挖掘及审计按实际用户意图触发，完成探索不擅自执行后续阶段。
2. **明确图组**：页面分别设置、预览与调整良品和异常图组，初始建议各 10 张，实际发送数量清晰可见。两组均非空、无重复且属于同一数据集，复用已有来源资格检查；来源不足时说明缺口。DSH 未获数量时先询问，不把来源总数当作发送数量。
3. **同时观察**：一次联合生成请求包含用户确认的全部两组图像，附候选角色与真实图像引用；标签是比较线索，不是质量真值。不先分组生成两套方向再文本拼接。复用模型配置和实际容量预检，不固定模型或视觉输入数量上限；失败后保留错误，降低数量或重试须由用户决定。
4. **开放方向**：从本批图像的共性、差异、正常变化和观察限制提出候选方向，不把当前通用方向作为必选答案；可返回空结果，不设方向数量配额。每项包含名称、可操作观察说明、适用良品/异常/两者、来源证据及限制；引用校验拒绝未送入的图像。方向是待采用的检查议题，不直接发布为已证实知识或缺陷。
5. **作业与追溯**：显示真实阶段、完成/失败状态和调用信息，支持取消、明确重试及刷新后恢复查看。冻结实际图组、角色、来源内容、提示词、有效模型及配置；输入变化不得混入旧执行。成功结果形成不可变版本，同一数据集可查看多个历史探索结果，失败或取消不替换成功结果。
6. **方向选项**：知识挖掘中增加“探索方向”组，按数据集、所选探索版本及当前良品/异常类型展示适用项，与通用和自定义方向并列。新结果默认未勾选，不覆盖既有配置；用户可勾选、修改名称/说明，保存后才用于下一次图组。探索页可跳转到该结果对应的知识挖掘选项。已采用方向保留原探索来源及实际保存内容，新探索或编辑不改写历史知识与作业。
7. **一个配置写入口**：探索结果库保存原始候选，既有挖掘配置保存用户实际采用的方向；采用与编辑通过现有配置服务统一保存。工作台与 DSH 共用选择操作，DSH 仅在用户明确要求采用时保存。挖掘作业继续冻结实际选项和提示词，不增加首批/后续批次概念。

## 页面交互

方向探索页使用项目现有按钮、表单、缩略图放大、作业状态和证据展开组件。顶部选择数据集，设置区分别配置两组图像及可选探索目标；结果区以紧凑列表展示方向名称、适用范围和观察说明，证据与限制按需展开。运行中保留图组与进度，空结果、失败和缺证明确可见。窄屏纵向排列，勾选、关闭弹窗与保存均支持键盘。

知识挖掘中的“探索方向”勾选、编辑和保存沿用现有方向编辑交互，避免新增平行配置页；来源及历史版本可追溯，尚未保存的选择不得进入模型请求。

## 实现边界

- 复用[来源资格](../../python/iad_core/knowledge/sources.py)、[模型与容量客户端](../../python/iad_core/workbench/vision.py)、[共享作业](../../python/iad_core/workbench/jobs.py)、[图像证据](../../python/iad_core/evidence/images.py)。新增探索领域负责混合图组、方向结果及版本，避免把探索当作普通知识发布。
- 复用[方向配置](../../python/iad_core/knowledge/prompts.py)作为采用后的写入口、[方向编辑](../../apps/iad-harness/src/client/components/KnowledgeDirections.tsx)作为选择界面。领域类型从 Python 生成前端契约，不重复维护。
- 复用[技能注册](../../apps/iad-harness/src/server/index.ts)、[页面导航](../../apps/iad-harness/src/shared/navigation.ts)与 HTTP/Python 桥接。流程写入独立技能，不塞进系统提示词。

## 交付切片与测试边界

1. 联合图组探索：公开操作验证来源资格、一次混合多图请求、结构化结果、非法引用和容量失败。
2. 作业与版本：公开查询验证终态、取消、重试、冻结输入变化、历史结果及证据读取。
3. 选择与挖掘：通过知识配置公开接口验证新方向可选、默认未采用、修改保存、跨数据集/类型隔离、下一次挖掘实际使用与历史不变。
4. DSH 与页面：验证技能真实注册/会话工具执行、六个侧栏入口、图组预览、方向选用、刷新与窄屏键盘操作；不以提示词文本匹配代替执行验收。

测试沿既有公开工作台 → HTTP/Python → 真实 SQLite 与图像资源；只替换外部 MLLM HTTP 响应。真实模型验收先用新生成的良品/异常合成图和隔离库，验证联合请求、结果、选择保存与后续知识挖掘，不修改生产业务数据。
