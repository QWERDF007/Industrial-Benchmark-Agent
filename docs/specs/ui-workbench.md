# 工作台 UI 重构规格

本规范覆盖工业工作台的页面设计、交互与验收。视觉和精确交互依据 `Industrial_Benchmark_UI_20261023.zip` 中的 `Industrial_Benchmark_Interactive.html`、`设计与开发方案.md`、`交互规格与验证.md`；该包以 0c614cf 为源码基线。严格按 HTML 落实尺寸与信息组织，不另创视觉方案。图中示例数据不作为真实业务结果；原型的计时作业和本地演示状态不进入生产。运行时视觉参数唯一来源为下文指向的主题与样式源码。

## 范围与约束

- 六个业务入口分为数据准备、知识构建、质量审核。【模型设置】位于辅助工具区；DSH 会话选择独立，提供商资料仍共用原生服务。审计配置只展示统一模型及设置入口，各功能共同引用同一工业模型配置。
- 数据集改为上方资源表与下方宽配置；图像默认卡片改为文件名和文字状态，分数进入详情。来源管理进入【良品来源】视图，普通图像浏览不新增“管理良品来源”按钮。
- 方向探索的结果、新建、作业互斥；知识页默认结果，新建配置独立；审计结果优先、配置抽屉；复核使用队列、大图与裁决三区。模型设置页同步使用共享层级与控件。
- 沿用 React 18、现有 HTTP/Python/SQLite、生成契约和 Workspace。替换旧布局并删除旧路径，不另建并存的 UI 或状态框架，不因 UI 重构更改模型参数、数据标签、质量口径及人审规则。

## 实施与测试边界

- 原生宿主导航扩展见[任务 V01](../tickets/ui-workbench.md)；页面/区域复用原有业务接口，只有当前视图挂载可交互内容。
- TDD 以公开工作台 → HTTP/Python → 真实 SQLite/PIL，以及原生 DSH 浏览器/会话为边界；仅替换外部 MLLM HTTP。优先扩充既有浏览器场景，不模拟 Workspace 内部状态来替代真实操作。
- 必须覆盖：跨页筛选/选图、tab 隔离与刷新恢复、120 图过滤范围而非当前 24 图、复核草稿/幂等提交/成功推进、bbox 与 mask 原像素对齐、原生会话往返。真实模型效果不作为普通布局验收前提。
- 实施顺序及依赖见[任务票据](../tickets/ui-workbench.md)。完整视觉与操作验收见文末，不以构建成功代替用户链验证。

## UI-01 导航与骨架

- 六个业务PageId及既有模型设置PageId不改名；业务章节顺序是数据准备、知识构建、质量审核，各两入口；模型设置归入辅助区。
- 每页只有一个h1；内部章节h2、字段组h3，不能只用大字号div假装章节。
- 工作区宽度由宿主容器决定，不依赖document选择器猜测左栏。
- 数据集管理不显示重复下拉；其它页只有一个数据集选择入口；切换后状态按既有数据集隔离。
- 正式导航接入保留新会话、工作区、插件、设置、折叠及选中态；采用正式契约，不操作宿主DOM。展开宽度目标220px，宿主几何若限制宽度，以真实宿主契约统一适配，不用业务CSS强压。
- h1、标签行、筛选、正文共用同一左边线；页头动作与正文右边界一致。
- 每页一个主要动作；进入新建视图后，主要动作由配置提交替代。会话、新会话、工作区、插件、设置和折叠均需真实可用。

## UI-02 间距、字体与控件

主题角色、字号、间距、圆角与控件边界统一由[主题](../../apps/iad-harness/src/client/theme.ts)和[控件](../../apps/iad-harness/src/client/controls.ts)定义；响应布局见[工作台样式](../../apps/iad-harness/src/client/styles.ts)。颜色数值以通过真实宿主对比度验收的源码为准，不另存第二份运行时token表。

- 数据行至少56px，两行64px；正文、标签及辅助信息采用共同层级，容器变窄时按主题间距重排。
- 图标按钮保持44px点击目标；同行字段和动作使用统一控件高度，不靠不同margin挪出假基线。
- 文本左对齐；计数/比例右对齐并使用tabular-nums；文件名一行ellipsis。取消全局overflow-wrap:anywhere，仅对必要的长元数据/错误折行。
- 单个内容区域最多一个带底色结构表面；不套卡片。无装饰性图标、无用途缩略图、重复KPI、无依据进度。
- 状态有文字，颜色辅助；禁用执行在相邻位置说明实际缺口，不常驻堆叠正常提示。
- 实现保持既有要求：正文对比度4.5:1，必要输入边界和焦点3:1，明暗主题均验收。AI图里的淡边框不是已通过测试的颜色值。

## UI-03 容器与滚动

C为业务根容器宽度。文字放大时允许内容最小尺寸推动页面滚动，字段区和提交区仍各自可达。

断点、列宽与区域间距的唯一实现源是[复核样式](../../apps/iad-harness/src/client/styles/review.ts)、[知识样式](../../apps/iad-harness/src/client/styles/knowledge.ts)、[表单样式](../../apps/iad-harness/src/client/styles/setup.ts)与[页面组合](../../apps/iad-harness/src/client/WorkbenchPage.tsx)。宽容器保留队列/画布/裁决，收窄后依次转为上下文面板；手机不缩小字号硬塞多栏。

- 普通页一个主滚动区。表格必要时局部横向滚动，不能让整页横向滚动。
- 复核占剩余高度，子区min-height:0；队列与证据详情可独立滚动，画布适配，裁决提交区不参与字段区滚动。
- 避免document、工作区和同一内容三层不必要滚动。
- 100%字号、1366×768和1920×1080真实宿主中能看到当前图和提交入口。200%字号允许重排及面板内滚动，不截断字段、不遮焦点。
- 保留375×812、小屏、深浅主题和字号放大的既有能力，不能只适配效果图画布。

## UI-04 列表与图片

- 数据集表格+下方配置，不设置只有一行也撑满的min-height。
- 数据集列表页长10，对已加载datasets客户端过滤/分页，不增加服务端协议。所选名称直接作为详情标题，目录与映射/基本信息互斥，章节标签与字段两栏组织；单页资源表不显示分页，空列表不显示分页。配置保留实际扫描结果；Labelme双路径、无标注来源开关、目录分类角色与重扫准入沿用；导入仍为简洁模态，ID按需展开，删除进入更多菜单。
- 图像pageSize保持24；卡片最小宽184、帧4:3、gap16，列数由空间决定，不固定五列。
- 状态查看与批量选择外观、语义分开；普通状态不用checkbox形状。
- 列表仅加载当页缩略图，object-fit:contain；不为整齐裁剪缺陷。
- Pagination仅一个；列表数与分页放底部或同一固定列表底部。
- 原图、bbox/mask、MLLM候选坐标由[共享画布](../../apps/iad-harness/src/client/components/ImageCanvas.tsx)统一计算，不因重排生成新标注；[全屏检视器](../../apps/iad-harness/src/client/components/ImageViewer.tsx)只负责模态呈现。

## UI-05 表单、选图与执行

- 长配置为独立页面视图，短审计配置为560px抽屉（窄屏全屏）；配置最大宽1040px，模态焦点复用现有dialog能力。
- 新建探索按目标、两组样例、运行确认分三章；新建挖掘按方式与依据、方向、图像范围、运行确认分四章。两组独立目标数量用短字段，只有选择与查看已选入口；按数量选取进入共用选择器。两组预览限量显示，完整图组在共用分页选择器中查看，不把预览数当已选数。
- SourcePicker共享呈现，候选kind/范围及资格规则由原调用方决定，不错误统一业务语义。
- 明示已选n/目标m；预览少于n时可查看全部已选。不能用当前页个数代替总选择数。
- 分页/搜索不丢已选；跨数据集不混选；正在选择/运行时沿用禁用规则。
- 开始前显示实际发送图组或完整过滤范围，不混淆候选总数、页面数和全库数。
- 隐藏配置不执行；启动成功定位作业；失败保留输入与错误。
- 只有确有未保存修改时才提示离开，不给查看动作增加确认。
- 容量失败、取消、重试、减量保留明确用户动作，不自动改变图组。

## UI-06 知识

- 类型、版本与来源集中在同一上下文行；窄屏按容器重排。
- results=判据，findings=待核实/标注核验，versions=版本，jobs=任务；setup独立。各标签不混渲染。
- 无knowledge时jobs仍可显示运行/失败任务；不以knowledge存在为挂载前提。
- 正常版本依据、预设、来源及冻结关系沿用原契约。
- 矛盾、待验证、有证据支持保持区分；无支持不能通过样式显示可信。
- freshness正常一行摘要；变化/未核实保留原因与修正入口；“额外候选未覆盖”不能说成知识错误。
- 列表与详情同步；切版本清除无效checkId；选中与滚动可恢复。

## UI-07 审计与报告

- 筛选工具条使用网格与侧栏上方的完整内容宽度；窄容器点击图像打开上下文详情，只挂载一个详情实例，关闭回原卡片。
- 样本侧栏图像遵循 HTML 的 156px 高度，保留原比例与标注坐标；模型观察和复核入口可达。
- results中不挂载完整AuditSetup；新建审计抽屉共享配置组件。
- 执行范围是当前filters所有图像，数量来自total，不是当前页长度。运行后不得把新筛选当作旧作业冻结范围。
- 模型建议仍为无明显异常/发现疑点/证据不足，人工结论另列。
- 审计抽屉展示统一工业提供商与模型，配置遵循[模型设置规格](workbench-model-settings.md)，不接受逐任务模型覆盖。
- 无审计显示尚未审计，缺失模型分不填0。
- 报告明确全部数据集、每图最新记录的现有范围；比例带分子分母；未评估不改0%。
- 标签不一致不是已验证模型错误率；此报告不是外部AD模型排名。

## UI-08 人工复核与冲突

- 五种裁决纵向排列；空记录与无匹配记录区分，不显示无效分页或复核队列遗留详情。历史详情仅由当前记录选择打开。
- 样本决策五种：PASS/HARD_NORMAL/FAIL/UNCERTAIN/SKIP，文案沿用api.ts。
- 未选、缺必填、提交中、待确认按既有规则控制；填表不直接写后端。
- 重试同一submission，不偷偷新建提交ID；失败保留草稿与就近错误。
- 默认pending筛选提交成功才推进；末页为空回有效页；结束显示完成空态。
- 非pending与历史查看不强制推进；“提交后下一张”仅在实际会推进时显示。
- 画布/表单绑定同一sampleId；迟到响应不覆盖当前样本。
- 知识冲突保留“保留/修订/退役判据/要求补证”；当前来源或版本不满足既有准入时不可提交。
- 待人工确认/待重核验/已生效不得合并。
- 不新增图中虚构的300字限制；保持实际字段契约。

## UI-09 作业与版本

- 列展示任务、类型、状态、完成/总数、失败、时间、操作；不存在的字段用未提供，不补造。
- 详情显示冻结依据、观察/发布计数、错误、父/根任务、源会话、已有重试。
- 作业的[模型配置快照](../../python/iad_core/workbench/model_profile.py)完整保留历史字段；当前执行配置继续严格校验，不将历史字段重新作为可执行设置。
- 完成和发布不同；观察完但未发布不能写成已完成发布。
- 无有效总量时显示真实阶段或不定进度，不模拟百分比。
- 非jobs页最多一行当前运行摘要，不重复完整列表。
- 选中任务不在列表时保留useJobs已有status补查与定位。

## UI-10 焦点、状态与导航

- 键盘可导航、切tab、选样本、开关面板、提交；focus-visible可见。
- 标签实现完整tablist/tab/tabpanel键盘模型，或语义一致的导航链接，不混用半套ARIA。
- 关闭面板焦点回发起控件；删除后回合理相邻行或列表标题。
- 空态、错误、加载明确区分；status用于普通反馈，alert用于需注意错误。
- 后退/刷新/Agent跳转及返回复用Workspace保存上下文。
- 主要动作有文字，减少动画偏好保留。

## UI-11 性能与验证

- 不新增模型调用、整库原图下载、逐行轮询。
- 分页、懒加载、取消请求不退化；1000条来源/任务fixture确认DOM受分页或折叠限制。
- 改前改后同环境记录响应、内存/DOM、请求数，无未经实测的提升承诺。
- 模型设置按选择/高级参数/提交区组织，提供商使用资源表；完整能力字段与原生凭据服务保持[模型设置规格](workbench-model-settings.md)边界。
- 真实截图和操作是验收证据；图像生成图不是测试证据。
- 代表业务链通过后停止无关测试扩张，既有必需门禁仍执行。

### 视觉与性能

- 1920×1080、1366×768、1280×800、375×812使用真实浏览器内容尺寸；代表模板检查明暗、100%/200%字号、键盘和焦点。1366×768正常字号可见当前图与提交入口。
- 同级起点与控件基线偏差不超过2 CSS px；长文件名与不同纵横比不破坏对齐；页面无横溢、提交栏不遮字段/焦点。
- 加载/空/失败/提交待确认使用真实状态；隐藏视图的控件不能获得焦点；没有装饰统计或图片示例冒充真实结果。
- 隔离fixture覆盖无/单/多数据集、两种格式、长路径、横/竖/极小图、bbox/polygon/mask、冲突/无支持、各作业终态、提交失败/待确认、pending末页。
- 同环境记录改前/后请求数、原图请求、翻页/切图耗时、DOM量、轮询次数。1000来源/作业由分页或按需详情限制DOM；不用整库重扫/重审当布局验收。
- 定向更新已有[布局验收](../../apps/iad-harness/browser/workbench-layout.js)、[表面验收](../../apps/iad-harness/browser/workbench-surfaces.js)、[工作台链](../../apps/iad-harness/browser/workbench.test.js)、[探索链](../../apps/iad-harness/browser/exploration.test.js)、[知识导航](../../apps/iad-harness/browser/knowledge-navigation.test.js)、[原生会话往返](../../apps/iad-harness/browser/session-handoff.test.js)。删除固化旧空间比例和必须存在KPI的断言，保留全部业务断言。
- 交付实际提交、命令结果和代表运行截图。最终至少通过A01/A03/A06/A08/A10/A11/A15及类型/构建门禁，余项按覆盖证据核对；生成效果图不是测试证据。
