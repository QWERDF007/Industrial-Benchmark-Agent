# 目录图像级异常检测数据集

本规格定义待确认的目标行为；当前实现入口见[架构索引](../architecture.md)。知识、审计和人审的通用规则沿用[数据集知识审计规格](dataset-knowledge-audit.md)，布局、组件和主题沿用[工作台设计](../design/workbench-ui.md)。

## 范围

在现有服务器目录导入中增加“异常检测目录（图像级标签）”，与 Labelme 并列。两种格式接入同一个数据集注册、扫描、查询、知识、MLLM 联合审计和人工复核流程。图像级格式不要求 JSON、矩形、多边形或掩膜，不生成占位区域标注。

本轮不增加浏览器上传、不引入传统异常检测训练管线、不自动重新划分 train/test、不实现像素级指标。目录标签可供质量核验，但不是人工复核或 Gold。

## 目录与标签

```text
/data1/data/产品A/
├── OK/
│   ├── 001.png
│   └── 批次1/002.png
├── NG/
│   ├── 003.png
│   └── 划伤/004.png
└── 待确认/005.png
```

| 相对目录 | 导入角色 | 图像级原始标签 | 区域标注 |
| --- | --- | --- | --- |
| OK 及其后代 | 正常 | PASS，界面显示 OK | 无 |
| NG 及其后代 | 异常 | FAIL，界面显示 NG | 无 |
| 待确认及未匹配图像 | 未标记 | UNCERTAIN | 无 |
| 用户显式排除的目录 | 排除 | 不导入 | 无 |

- 扫描支持子目录递归；相同文件名通过根目录相对路径区分。根目录直接放置的图像默认未标记。
- `OK/good/normal` 与 `NG/bad/abnormal/anomaly/defect` 仅作为大小写不敏感的完整目录名识别建议；预览显示实际映射。禁止包含匹配、文件名猜测或“不是 OK 就是 NG”。其他名称由用户/Agent 明确映射。
- 确认后保存根目录下的相对目录规则，扫描按规则执行，不在每次扫描重新猜标签。每张图只能属于一个角色；嵌套规则重叠、同一目录多重角色和 OK/NG 祖先语义冲突必须在预览解决，不能按遍历先后取值。
- 支持指定 `train/good`、`test/good`、`test/NG` 等实际目录。保留目录结构，不把 train/test 当质量标签，也不自动改变既有数据划分。
- 可只导入 OK、只导入 NG 或包含未标记图；没有合格正常来源时提示补充或人工确认良品，再启动依赖正常知识的作业。没有 NG 时跳过不良知识挖掘，仍可基于正常知识审计。
- `NG/划伤` 首期只保留来源路径，不自动赋予已核实缺陷类别；NG 表示图像整体异常标签，不表示异常位置或原因已确定。

## 导入与管理交互

沿用现有“添加数据集”弹窗，顶部使用格式单选项，避免再套一层页面。

| 格式 | 必填输入 | 预览内容 |
| --- | --- | --- |
| Labelme | 名称、图像目录、标注目录 | 沿用区域标注接入能力 |
| 异常检测目录 | 名称、服务器根目录 | 实际子目录、正常/异常/未标记/排除映射及图像数 |

异常检测目录步骤：填写目录 → 扫描预览 → 调整映射 → 导入。名称默认取根目录名，可修改；预览为紧凑列表，每行“目录 / 数量 / 角色”，使用共享表单组件。默认显示必要项，不出现无意义的标注目录输入或“无标注作为良品”开关。

- 预览区分发现的文件数与实际导入成功数；损坏图像沿用导入问题，不将缺少 JSON 视为问题。
- 未标记目录可保留为未标记或显式排除；重叠和冲突必须解决后才能提交。预览无图片、目录无权限时就地报错并保留输入。
- 预览不登记数据；提交重新校验路径、规则和扫描范围。预览后范围或规则变化时刷新预览，不发布未确认的标签分布。实际扫描沿用原子发布。
- 卡片沿用当前大小和布局，显示名称、图像数量；Labelme 显示“区域标注：N”，图像级格式显示“图像标签：N”。图像标签数为有明确 OK/NG 标签的图像数，不计未标记，也不冒充区域数量。
- 详情在名称与 ID 后显示格式、OK/NG/未标记数量、根目录与映射；映射修改使用“保存并重新扫描”，影响范围先预览。名称继续沿用现有回车/失焦保存。
- 浏览筛选分为“原始图像标签：OK / NG / 未标记”和“区域标注：有 / 无 / 类别”。格式无区域标注时隐藏区域筛选。两组维度独立，原始标签、模型建议和人审结果不混成一个状态。
- 图像详情独立显示原始图像标签与来源目录、模型建议、人工决定；无区域标注时不显示空框或绘制伪标注。缩略卡继续保持既定的状态方块、文件名和分数布局。

## 标签、来源与持久化

1. `samples.quality_status / quality_source` 继续作为当前导入图像标签及其来源的唯一事实入口；目录规则属于数据集配置。不在 annotations 再复制 OK/NG 标签。区域表只保存真实区域标注，当前目录格式区域数量为零。
2. 格式使用强类型区分的导入契约：`labelme` 分支要求标注目录，`folder_classification` 分支要求根目录与目录角色规则；HTTP、DSH 工具、配置和前端生成契约指向同一定义。
3. 来源记录包含匹配的相对目录与映射语义，不能只写含混的 imported。正常来源资格、异常来源资格和筛选由统一领域规则派生，界面和 Agent 不各算一份。
4. 人审决定作为独立事实保留；它决定来源资格时优先于导入标签。人审 FAIL 不进入正常池，人审 PASS/HARD_NORMAL 不进入异常池；原始目录标签不被覆盖，冲突可查阅。UNCERTAIN/SKIP 不充当确认标签。
5. 图像级格式只从明确 OK 或有效人工正常决定产生自动正常来源。未标记图不因没有区域标注而自动进入正常池。人工选取仍须通过共享资格校验，不可绕过 NG/人审异常限制。
6. 明确 NG 可作为“导入异常候选”直接进入不良知识挖掘，补齐现有仅有人工异常、区域标注或模型疑点的资格路径；模型必须验证视觉依据，不能因为 NG 就生成确定异常知识。
7. 图像内容、原始标签、匹配规则语义、人工反馈与来源资格纳入知识/作业的冻结输入指纹；规则或标签变化可被检测，旧知识显示来源变化，旧作业重试不得悄悄混入新标签。保留原知识与审计证据。
8. 同数据集重新扫描保留同一相对路径的样本身份和人工记录；修改映射不改变 UUID。文件移动导致相对路径变化时沿用现有身份规则，不承诺自动迁移历史。已有数据集切换格式不在本轮范围。
9. 重复来源检测同时覆盖两种格式，阻止将同一图像根目录再次注册成相互矛盾的数据集；复用既有身份并编辑其规则。不同类别/产品建议分别接入，不跨产品混合学习。

## MLLM 知识与审计

```text
OK 候选 → 正常知识版本
NG 候选 + 正常知识 → 待视觉核验的异常知识版本
冻结知识 + 每张全图 + 原分辨率细节分块 → 联合审计
审计建议 ↔ 原始图像标签 → 冲突与疑点 → 人工复核
```

- 延续现有 MLLM 机制。没有区域标注时使用当前证据规划的全图细节覆盖；需要定位时由模型提出待核验区域，再从原图裁剪细看。覆盖分块、模型提议 ROI 与导入标注使用不同来源类型。
- 全图、局部、位置和光照在现有联合分析中关联；上下文足够时一次多图输入，不重新引入“单独看全图、逐 ROI 独立判定”的路径。
- 学习 NG 时目录标签只说明候选来源，不等于可见缺陷。模型看不出异常时保留不确定、正常替代解释或标签可疑，不能强制归纳出一个缺陷。
- 审计待审图时屏蔽其 OK/NG 标签、含标签的目录/文件名及其他等价泄漏字段；传给 MLLM 的图像/证据使用中性编号，本地保留可追溯映射。模型结构化建议保存后，再由系统与原始标签比较，形成标签不一致提示。
- 禁止用待审图自身或同内容副本提供的知识作为唯一判据；沿用独立来源校验。全数据集参与知识挖掘后的审计属于数据质量核验，不能宣称独立测试集准确率。
- 图像级数据没有区域真值；不计算框/分割准确率或 IoU，也不因缺少人工框而标为缺证。缺证应来自实际细节、视觉覆盖或检查依据不足。
- 报告保留现有三项质量口径，增加原始标签分布、已审计标签分布、模型与原始标签不一致数量/比例及统计分母；未标记、UNCERTAIN、失败和未审计分别列出。该一致性比例不命名为准确率。独立分类评测与业务总分另行设计。

## Agent 接入

用户可说：“服务器 /data1/data/产品A，OK 是良品、NG 是不良品，挖掘知识并审计。”Agent 读取真实目录预览，按明确规则调用统一导入接口；名称默认使用目录名。常见目录识别无歧义时展示实际映射并继续已有授权流程，有歧义时只询问未确定的目录角色。

只给服务器根目录时，Agent 同时检查格式候选；存在 Labelme 与目录标签两种可能时不静默覆盖，应询问格式。会话与页面使用同一个预览、导入、重新扫描和资格查询，不能在提示词中维护另一套目录识别或正负样本规则。后续技能继续调用既有知识/审计/报告工具，侧栏可查看同一批结果。

## 实施边界与验收

| 切片 | 主要交付 | 必要验证 |
| --- | --- | --- |
| 目录接入与数据契约 | 类型化格式、预览、严格映射、原子扫描、原始标签来源 | OK/NG/未知/仅单类、递归与同名、冲突/重叠、损坏图、重复根目录、重扫身份 |
| 知识与冻结输入 | 统一资格、NG 候选、标签与规则指纹 | NG 不入正常池、未标记不自动良品、人审优先、不确定不冒充确认、映射变更阻止旧输入恢复 |
| 工作台交互 | 分格式表单、映射预览、详情与筛选、标签对照 | 真浏览器导入/编辑/重扫、两种格式回归、明暗/窄屏/键盘操作 |
| MLLM 与 Agent 闭环 | 无区域联合证据、审计标签屏蔽、分项报告与对话接入 | 捕获实际送模请求确认不泄漏原标签、ROI来源正确、真实DSH对话调用与逐图进度；真实MLLM使用合成OK/NG图验证 |

先编写涉及下一层依赖的定向测试，再实施；只替换外部 MLLM HTTP 响应，数据库、文件、领域服务与公开工作台链路使用真实资源。未确认本规格前只维护设计文档，不改业务代码。
